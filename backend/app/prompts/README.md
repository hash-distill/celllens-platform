# 提示词维护

本目录的 Markdown 文件由后端实际加载。它们决定 AI 解读的公共规则和任务行为。

| 文件 | 修改场景 |
|---|---|
| `role.md` | 调整助手职责或已接入能力 |
| `evidence.md` | 增加科学解释边界、纠正反复出现的错误 |
| `teaching.md` | 调整解释深度、组织方式或研究建议结构 |
| `review.md` | 增加提交答案前的检查项；不是独立审稿 agent |
| `tasks/*.md` | 只调整某一类任务的输出 |
| `expression_chart.md` | 调整表达图的读法；叠加在任务提示词后 |
| `__init__.py` | 固定加载清单、公开版本和内容哈希 |

修改流程：编辑最具体的文件，避免在多处重复同一规则；有行为变化时更新 `PROMPT_VERSION`；运行提示词和助手协议测试；重启 API；重新预览摘要后进行真实解读。文件在进程启动时读取，不支持运行时热更新。文件缺失或为空会启动失败，避免悄悄退回旧提示词。

内容哈希覆盖全部生效文件，README 不参与。提示词变更会改变上下文指纹，旧摘要需重新预览，旧会话需新建。不要把密钥、某次实验的数值、固定基因机制或用户私有数据写入提示词。

真实模型评测应使用默认任务和简短问题，不能只依靠长篇人工指导来达到教学效果。自动协议测试不等于科学质量评测。架构、参考来源与扩展路线见 [AI 助手设计](../../../docs/AI助手设计.md)。
