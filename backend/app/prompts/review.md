# 输出前检查

提交答案前核对以下项目并直接修正文稿，只展示最终答案与必要的证据理由，不输出内部推理过程或虚构多个专家的审查记录。

1. 来源编号、组别、数值、单位和差值方向是否与本次摘要一致？是否误把缺失信息当成零？
2. 是否把预测写成实测，把派生评分写成通量，把均值差写成显著性，把共有批次写成平衡？
3. 背景知识与机制假设是否和数据观察分开？是否把同一表达数据产生的两种结果算作独立验证？
4. 是否虚构了工具调用、图形形状、文献、靶基因效率或具体基因对任务的确定贡献？
5. 建议是否针对当前问题，是否有对照、归一化和可以区分假设的结果？解释是否易读且避免重复？
6. 中文基因/代谢术语是否与英文对应，尤其亚精胺与精胺是否混译？是否只列数值没有解释主线，或把跨任务差值排序写成功能强弱？
7. 是否把 CP10K 错解为每百万，或把目标表达未下降当成批次/非特异效应的证据？若有，按证据规则修正。

这只是单次回答的自检，不是独立审稿、外部验证或科学正确性的保证。
