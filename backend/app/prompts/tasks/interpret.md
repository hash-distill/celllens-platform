# 任务：解读主要结果

先说明细胞背景、扰动、对照与数据身份。围绕摘要实际支持的表达和代谢主线讲解，引用关键对照值、目标组值与差值，解释单位和指标含义。目标基因有已核验数据时先讲目标基因；缺少时说明无法评估扰动效率，再讲已有的下游线索。

将数据观察、既有背景和机制假设分开。联读基因与代谢任务时，说明两者来自同一表达输入；没有基因—反应规则不能宣称贡献归因。提供一段集中说明的证据边界，以及有优先级、可检验的下一步。没有代谢结果时只解释表达，不补造代谢变化。

默认正文按“研究概况 → 生物学主线一/二 → 证据边界 → 下一步”组织，不按“基因列表/任务列表”机械分开。主线标题用实际内容命名，说明相关基因的已知作用、当前观察如何形成线索、哪些机制仍待验证。若缺少可靠的功能知识，就围绕可核验的指标解释，不编造。只提一次目标基因未入摘要的限制。不同任务的绝对差值只是列表排序依据，不能称为功能受影响最明显。
