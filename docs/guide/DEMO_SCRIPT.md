## 打开结果

在工作台选择背景、“结果回放”和 ALDOA，读取已保存的真实模型结果，再点击“解读本次实验”。也可直接打开已完成的在线或实测对照实验。四个章节始终绑定同一运行；回放保留原运行与哈希，本次不重新执行模型。讲解中的变化方向和数值以所选实验为准。

## 讲解流程

| 时间 | 页面操作 | 讲解重点 |
|---|---|---|
| 0–15 秒 | 实验问题：查看背景、目标、模式与来源 | 从一次单基因扰动出发，预测表达，再分析表达支持的代谢任务。 |
| 15–35 秒 | 状态与表达：比较共同 PCA 分布，选择基因 | 点表示单细胞表达状态；平均表达差用于描述变化，点不是同一细胞的前后配对。 |
| 35–60 秒 | 代谢功能：选任务、反应和 GPR | 对照、预测与可用实测共享布局，数值与知识关联均来自该运行；分数不等于通量，关联不等于因果。 |
| 60–78 秒 | 证据与验证：核对来源、完整性与观测指标 | 检查模型覆盖哪些基因、缺少哪些信息，并将预测与匹配观测和不变化基线比较。 |
| 78–90 秒 | 返回工作台：加入比较或导出结果 | 保留运行与来源，用于候选研究、老师核查和后续实验设计。 |

当前匹配观测的训练排除关系未核实，讲解时应说明这是本次观测比较，不作为独立留出泛化评价。没有第二个可比实验时，可只展示当前结果与导出。

## 操作

- 方向键切换章节，空格播放或暂停，Esc 返回同一运行的工作台；输入框与原生按钮保留自身键盘行为。
- 自动播放可随时暂停，页面隐藏后停止推进。
- 报告和科研图读取当前运行；阅读已有结果不会触发新的 GPU 推理。
- 使用实际系统页面和可追溯结果讲解。
