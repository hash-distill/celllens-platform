# 实测数据与预测对比

更新：2026-10-15。

打开实验记录，进入已完成实验，选择 **实测对比** 页签。新建实验时也可以点击扰动输入处的“已登记实测数据”快捷项；它只选择扰动，不自动提交实验。有匹配实测的新在线实验在预测完成后自动准备比较。

## 可查看的内容

- 实测对照、模型预测、扰动后实测三组细胞数、均值及变化。
- 完整成对基因/任务的预测变化与实测变化散点和逐项误差。
- 变化 Pearson/Spearman、MSE/MAE、不变化基线及差异表达诊断。
- 完整基因/任务 CSV 和含指标、来源、批次匹配、绑定哈希的 JSON。
- 实测来源核实失败时停止展示；没有观测时不填补、不生成比较指标。

## 如何阅读指标

评价比较相对实测对照的变化：`预测变化 = 预测均值 − 对照均值`，`实测变化 = 实测扰动均值 − 对照均值`。表达使用统一的 `mean(log1p(CP10K))` 尺度。

| 指标 | 含义 |
|---|---|
| 变化 Pearson | 线性趋势一致性，范围 −1 至 1；高相关不单独证明幅度正确 |
| 变化 Spearman | 变化排序的一致性 |
| MSE / MAE | 预测变化与实测变化的误差，越小越好 |
| MSE / 不变化基线 | 假定扰动后保持对照不变作为基线；小于 1 说明本案例模型误差更小 |
| 差异表达诊断 | 预测与实测分别对照真实对照，使用 Scanpy Wilcoxon、tie correction、BH-FDR < 0.05 |

表达指标参照 [Arc Cell-Eval](https://github.com/ArcInstitute/cell-eval)；本批五个当前可用案例均与本机官方 Cell-Eval 0.8.2 的 `pearson_delta`、`mse_delta`、`mae_delta` 交叉核对一致。DE 采用 [Scanpy](https://scanpy.readthedocs.io/en/stable/generated/scanpy.tl.rank_genes_groups.html)，页面注明项目 Overlap@N/AP 的具体实现，没有将其称为完整官方 profile。

评价保留合法零变化和差于基线的案例，不根据效果挑选记录。无显著基因等不可计算情况显示缺失，不造完美分数。

## 来源与解释边界

真实测量来自官方 [State-Replogle-Filtered](https://huggingface.co/datasets/arcinstitute/State-Replogle-Filtered/tree/d790193bb2c93726541a75ca3fa873a92ed44da5)，固定 revision `d790193bb2c93726541a75ca3fa873a92ed44da5` 的 `replogle_concat.h5ad`。保留原表达值、源行号、条形码、背景、扰动与批次，不复制、补零或生成测量。

当前盘点 15 个已有案例组合，其中 8 个有测量，共保存 627 个真实细胞；不是全部模型扰动目标都有实测的承诺。

比较仅使用三组共有批次，保留各批次原频率；非配对群体的评价子集可能小于原实验展示群体，因此均值可能与原实验全量页面不同。页面显示输入/保留数，预测细胞不能逐一对应实测细胞。

代谢任务是预测 RNA 与实测 RNA 各自经过同一 scCellFie 流程的派生评分，不是实测代谢通量。检查点训练排除关系仍未核实，所有比较保持“匹配实测诊断”身份；细胞级检验不能代替独立生物学重复。

原预测文件与摘要保持原样，比较单独保存并绑定原始哈希。比较准备中自动刷新；准备失败保留原预测及失败产物，维护人员修正后可用独立尝试重新准备。辅助解读也可读取经过核验的比较摘要，仍需用户手动触发，不自动调用外部模型。
