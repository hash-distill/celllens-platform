# 代谢功能可视化

更新日期：2026-10-12。入口为实验的“代谢功能 → 功能前后对比”；结果解读使用同一界面。响应概览中原“查看功能前后对比”横幅已删除。

## 操作

1. 左侧搜索、分类筛选或选择本次对照、预测、差值均为有限数值且差值非零的代谢任务。默认按预测变化绝对值排序，每页默认 20 项，可选每页数量；未评分任务不补零。
2. 主图默认 UMAP，也可切换 PCA。坐标由本次保存的逐细胞 scCellFie 任务分数计算；切换任务仅改变着色和分布，不重新拟合坐标。
3. 图 A 区分对照、模型预测和可用实测；图 B 在相同坐标和色标上显示所选任务的原始分数；图 C 显示完整有效群体的累积分布。下表提供均值、中位数、四分位区间及相对对照的均值差。
4. “有预测变化的反应与基因”默认折叠。仅保留反应及关联基因都有完整、有限、非零预测变化的评分链路。原始 GPR 可能含有未评分名称，因此不在结果页展示；关联不代表因果贡献。原有基因—反应—任务节点图已从此界面移除。
5. 可导出 SVG / PDF 矢量图、300 dpi PNG 和图表 JSON；“导出关联 JSON”采用相同链路筛选，保留单位、来源哈希及筛选标记。导出不修改原始运行结果。

## 降维输入

按冻结细胞 ID 和来源对齐逐细胞任务分数，保留所有群体数值完整、且对照标准差大于 1e-12 的任务列。缺失或非有限值所在列排除；对照中无变化的列排除；不填零、不插补。至少需要两个可用任务及两个对照细胞。

所有群体使用对照均值和标准差进行同一标准化，防止分数范围较大的任务主导距离。图 B 着色、图 C 和统计表继续使用所选任务的原始 scCellFie 分数。参与降维的任务名单、排除原因、标准化参数在图表 JSON 中保存。

PCA 只在标准化后的对照上拟合两个成分；预测和实测使用同一中心和基底。UMAP 使用各群体共同拟合的最多 50 个主成分，邻居数 min(30, 细胞数 − 1)、min_dist=0.3、欧氏距离、random_state=42、单线程拟合。两种方法分别缓存，切换任务复用同一坐标。

该图的坐标是**代谢任务空间**；响应概览和单细胞状态仍是**表达空间**。表达空间中的任务着色与本页的代谢降维是不同分析，见 [单细胞科研图](SCIENTIFIC_CELL_STATE.md)。

## 来源与边界

本页只读取现有冻结结果，不重新运行模型或 scCellFie。清单、输入文件哈希、群体筛选、基因均值及任务细胞 ID 均需通过核对。关联记录缺失不阻止独立可核验的代谢图；逐细胞评分或降维输入不可用时给出具体原因。

scCellFie 分数不等于代谢通量。坐标不是细胞形态、真实空间或轨迹；群体不逐细胞配对。UMAP 间距、密度及分隔程度不量化效应大小或显著性，不同实验独立拟合的坐标不能直接比较。PCA 解释方差属于对照参考，不是预测准确率。

GPR 表示冻结知识库关联，不是已证明的驱动基因或因果贡献。模型覆盖目录集中在 `/coverage`，不在每个实验重复完整性统计面板。

“任务与反应分数”列表的关联基因来自本次完整冻结追溯，按当前分页读取，先筛选有效预测变化再展开名称；无合格链路时不展示名称。`determinant_genes` 是尚未验证的驱动归因字段，不用于替代关联。两个实验没有扰动后实测时隐藏空观测列。覆盖目录仍独立提供知识库范围说明，不把目录关联当作本次实验结果。

当前筛选确认的是保存数值发生变化，不是统计显著性、实测效应或已验证因果关系。验收见 [预测展示标准](../verification/2026-10-12-prediction-evidence.md)。
