# 功能前后对比

更新日期：2026-10-09。入口为实验工作台“代谢功能 → 功能前后对比”，同处另一个视图提供任务分数与数据覆盖。也可从响应概览打开，结果解读第三章使用同一界面。

这个视图帮助回答：预测哪些功能发生变化、关联哪些反应和基因、这些解释的数据覆盖有多少，以及保存的实测是否与预测相符。

## 操作顺序

1. 打开一个完成的实验；四个细胞背景均使用该实验自己的保存结果。
2. 左侧搜索或按功能分类筛选任务。默认按预测变化绝对值排序，支持按名称排序与每页 50 项分页。这里展示已保存且可评分的任务，未评分任务不会补零。
3. “前后对比”显示对照和扰动后模型预测。两侧的节点、位置和同类色标相同；暖色越深表示该类分数越高，升降需要看“变化量”。
4. “变化量”显示预测减对照。暖色为上升、冷色为下降，零值与灰色虚线缺失节点分别显示。基因表达、反应分数和任务分数各有独立单位及色标，不能跨类比较。
5. 下方反应列表展示该任务的全部保存关联，点击某个反应展开其所有关联基因。图是当前反应的局部网络；大量基因可在图内滚动，详情中的“全部关联基因”仍提供完整列表。
6. 点击图中基因、反应或任务，右侧查看对照、预测、预测差值和保存观测差值。支持键盘聚焦后按 Enter / 空格。右侧保留当前反应的原始 GPR 规则、任务/反应的官方完整性及冻结来源；真实回放可链接回原始运行。
7. 有真实观测记录时，提供“预测与实测”，实测均值以同一对照均值加保存的观测差值恢复，界面明确标出这一取值方式。缺少观测不显示该按钮，也不会制造观测结果。
8. “导出关联 JSON”下载该任务的完整冻结关联、数值、单位、数据库哈希及当前显示选择；不会改写服务器上的历史结果。

## 怎样读一条线索

例如，在保存的 HepG2 / ACD 在线运行 `run_c76a0442621c4e0d` 中，“ATP generation from glucose (hypoxic conditions) - glycolysis”任务分数由 6.9518 变为 6.7086，差值 −0.2433。选中 ENO 可查看 ENO1、ENO2、ENO3 及原始 OR 规则；ENO3 缺失会显示“未提供”。任务官方全部基因覆盖为 6 / 15（40.0%），影响加权完整性为 85.7%。这是该次运行的功能线索，不应推广为 ACD 已被实验证明降低 ATP 产量。

该任务所有 7 个反应可逐个钻取。其他任务可能关联更多反应，例如本次赖氨酸降解关联 92 个反应，因此列表提供分页，完整 JSON 保留全部关联。

## 来源和边界

- 连线来自本次冻结知识库，表示基因—反应—任务关联。当前资料没有完整化学计量与代谢物拓扑，界面不把这些线画成实测物质流或已证明的因果链。
- scCellFie 分数不等于代谢通量。群体均值不是同一细胞的前后配对，变化幅度不是统计显著性或模型置信度。
- 官方完整性说明输入基因的覆盖；预测可靠性仍需查看本次验证页。有匹配实测的诊断也尚非独立留出验收。
- 网络布局用于阅读关联，不代表细胞空间位置。“查看逐细胞功能分布”打开本任务的共同 PCA、指标着色和分布图，见 [单细胞科研图](SCIENTIFIC_CELL_STATE.md)。
- 历史合成记录保留明确来源标记，不提供真实功能网络。关联文件缺失或损坏时提示具体问题，可重试对应区域。
