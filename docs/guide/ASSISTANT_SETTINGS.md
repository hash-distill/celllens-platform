# 外观与大模型辅助解读

右上角“设置”进入 `/settings`。右侧快捷栏提供亮暗切换、直达顶部、直达底部、设置和使用说明；窄屏显示在右下方。主题可以选择浅色、深色或跟随系统，偏好保存在当前浏览器。科学图的数据配色与导出内容保持原有语义。

## 配置连接

1. 填写 OpenAI 兼容服务基础地址和准确的模型名称。基础地址包含服务需要的 `/v1` 等前缀，不包含 `/chat/completions`。
2. 填写自己的 API Key，选择输出预算及服务支持的参数字段。OpenAI 使用 `max_completion_tokens`；其他兼容服务可选择 `max_tokens`。推理模型的预算可能包含思考 token。
3. “测试连接”发送一条简短消息，可能消耗服务额度。连接成功后保存配置。
4. 打开已完成的实验或上传分析，在“大模型辅助解读”选择任务、预览摘要，再点击“发送摘要并生成解读”。

服务地址、模型和预算保存在当前浏览器 localStorage。API Key 保存在当前标签页的 sessionStorage，并在请求期间暂存于后端内存；不写入共享数据库、运行清单或分析文件。刷新页面仍可使用；浏览器恢复会话或复制标签页可能保留密钥。离开共享设备前请点击“清除 API Key”。浏览器禁止存储时，配置仅在当前页面内生效。多用户远程部署应通过 HTTPS 提供网站。

## 发送内容与结果

系统从当前已完成记录生成摘要，校验所读取产物的登记哈希。在线结果包含来源、表达单位合同、摘要中的前 20 行基因和代谢任务，以及可用的官方完整性总体统计；上传分析包含质控、分组方法、输入单位、前 20 行基因及任务和代谢完整性统计。前 20 行沿用已保存报告顺序，不是完整结果或重新进行的统计筛选。

摘要不包含逐细胞表达矩阵、PCA 坐标、完整上传文件、自由文本数据说明或源文件路径。分组名称和背景信息仍属于结果摘要的一部分，发送前应检查页面中的完整预览。生成时再次核对摘要 SHA-256，内容发生变化会要求重新预览。

可选任务为主要结果解读、覆盖与局限说明、后续科研验证建议。大模型输出作为独立纯文本展示，不修改原始科学结果、任务状态或数据。生成文本可能错误，不能代替原始证据、显著性检验或生物学验证；覆盖不等于准确率，scCellFie 分数不等于实测通量。解读仅保留在当前页面，可下载包含模型、时间、来源、摘要哈希和服务返回 token 用量的 JSON。

## 自定义与本机服务

默认允许 `https://api.openai.com`、`https://api.deepseek.com`、`https://api.siliconflow.cn`。其他服务由管理员在 `.env` 中登记**完整 origin**（协议、主机及端口，不带路径），重启后端后生效：

```dotenv
CELLLENS_ASSISTANT_EXTRA_ORIGINS=https://models.example.org,http://127.0.0.1:11434
CELLLENS_ASSISTANT_TIMEOUT_SECONDS=90
```

设置页面会列出当前允许范围。用户可将基础地址填写为 `http://127.0.0.1:11434/v1`；这里的本机是运行 CellLens 后端的机器。额外地址由部署者信任并管理，避免加入不受控域名或敏感内网服务。前端不能修改部署的数据库、GPU、文件路径和资源限制。

后端不跟随重定向、不读取代理环境变量、不自动重试；单进程最多同时处理 2 个大模型请求，请求体不超过 64 KiB、摘要不超过 48,000 字节、响应不超过 128 KiB，超时配置范围 5–90 秒。错误提示不会返回上游错误正文或密钥。兼容接口不包含工具调用、自动执行或模型训练。

协议参考：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。服务商的具体模型可用性、额度、数据保留和 token 参数以其文档为准。
