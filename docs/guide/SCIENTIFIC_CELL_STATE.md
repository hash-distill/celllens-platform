# 扰动前后细胞表达／代谢状态的分布变化

更新日期：2026-10-21。“响应概览”默认展开表达 UMAP 科研图；“表达状态分布”使用表达对照参考 PCA。基因详情可打开对应逐细胞分布。“代谢功能”展示任务分数空间 UMAP/PCA，见 [代谢状态分布与功能关联](FUNCTION_WORKSPACE.md)。这些图比较对照、扰动后预测与可用实测的群体特征分布，不重建细胞形态、细胞器结构或真实三维位置。

## 图能回答什么

- **A 整体状态分布**：每点一个细胞，蓝圆为对照、橙叉为预测、绿三角为实测。表达页观察表达特征分布，代谢页观察任务分数特征分布；比较共同坐标中的重叠、分散与偏移，不逐点连线。点云的形状不是细胞的外形，分布偏移不是细胞的物理移动。
- **B 指标着色**：位置与 A 相同，颜色表示选定的基因表达或代谢任务分数。所有来源共用数值色标，蓝低、黄高，缺失为灰，零值有效。
- **C 累积分布（ECDF）**：横轴是指标，纵轴是不超过该数值的细胞比例。曲线右移通常表示数值较高，交叉则未必存在一致高低排序。按比例比较，避免将 1024 与 64 的点数差解释为生物学变化。下方给出完整有效群体的均值、中位数与四分位区间。

选择基因或代谢任务，可搜索指标；列表按本次预测均值变化绝对值排序。默认基因优先使用扰动基因；不在模型表达面板中时使用变化最大的可用基因，不补造缺失基因。

结果页仅提供对照、预测和差值完整、有限且均值差非零的指标。所选指标的逐细胞群体也需完整，否则隐藏图表并说明原因。此筛选不改变降维输入、坐标或原始数据，不能解释为显著性或因果验证。

HepG2／ACD 的 ENO1 对照均值约 3.1043、预测均值约 3.0770，差约 −0.0272。图 C 可观察整个群体的分布是否变化，不能仅据此宣称差异显著。ACD 本身不在这次 2000 基因面板中。

## 方法与核对

校验注册清单及冻结输入哈希，重建本次表达槽、基因身份、扰动筛选和共同批次筛选。实测缺少模型表达槽时，`.X` 必须与冻结身份列一致且通过已有全部基因均值核对。真实回放通过原始清单定位预测文件，不重新推理或评分，不修改运行产物。

在完整对照的共同基因 log1p(CP10K) 表达上拟合两个 PCA 成分，预测和实测共用对照中心与基底。仅中心化，不按基因方差标准化，也不再次归一化模型面板。解释方差属于对照参考，不是预测准确率；HepG2／ACD 前两轴约解释 8.46%，二维只保留部分高维信息。

概览 UMAP 使用同一次实验经过上述来源核对的对照、预测和可用实测群体。所有群体先共同拟合最多 50 个表达主成分，再联合拟合一个 UMAP，保留原始细胞数量，不复制或补造细胞。邻居数为 min(30, 细胞数 − 1)，min_dist=0.3，欧氏距离，random_state=42，单线程拟合；过小样本使用随机初始化以避免谱分解失效。坐标按来源和细胞 ID 对齐，切换着色指标不重新拟合。JSON 保存实际参数、主成分数和 UMAP/scikit-learn 版本。

UMAP 坐标轴没有解释方差比例；点群间距、密度或分隔程度不量化扰动效应或预测准确率。不同实验独立拟合的 UMAP 坐标不可直接比较。[UMAP 参数与方法说明](https://umap-learn.readthedocs.io/en/latest/parameters.html)

任务值来自保存的逐细胞 scCellFie CSV，按唯一细胞 ID 和来源匹配，拒绝不匹配的数据。分布使用全部有效细胞；散点每来源最多占 12000 点预算的均等份额，抽样固定 seed=42。JSON 包含显示点、完整 ECDF 和群体统计，不包含完整表达矩阵。

## 导出与边界

SVG / PDF 是矢量图，PNG 为 300 dpi（4200×2580）。页面和导出共用 Matplotlib 数据与渲染；图内记录单位、样本数、方法、运行编号、来源和清单哈希，可放大阅读。

表达与代谢特征坐标不是细胞形态、细胞器结构、真实空间或实测轨迹；群体不逐细胞配对，不能据此追踪同一个细胞扰动前后的迁移。任务分数不是代谢通量、ATP 产量或浓度。细胞数不能替代生物学重复，不自动提供显著性星号、P 值、置信区间或因果箭头。预测准确性仍需阅读验证结果与留出协议。

缺少核验来源、哈希不符、细胞 ID 不符或旧合成演示时，科研图明确不可用。旧随机投影产物保留为历史记录，概览使用共同 UMAP，详细分析保留共同 PCA。后端尚未加载 UMAP 时，前端提示重启服务，拒绝将旧 PCA 坐标标成 UMAP。

“代谢功能”是唯一代谢主标签，内部包含“功能前后对比”和“任务与反应分数”。旧 `tab=function` 链接转入 `tab=metabolism&view=function`。代谢图用 `space=metabolic&feature_kind=task` 获取；默认 `space=expression` 保留本页表达图行为。图表 JSON 的 `embedding_space` 和 `embedding_preprocessing` 记录实际输入，图注和下载文件名区分两种空间。服务未加载代谢空间功能时明确提示，不把旧表达坐标标成代谢坐标。
