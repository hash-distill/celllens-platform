# 用户数据与下游分析

上传数据工作流从实测表达矩阵开始，不要求用户提供 STATE 模型权重。上传的数据可以超出现有 K562、RPE1、Jurkat、HepG2 预设数据；人类代谢分析仍需满足基因身份、表达尺度与冻结数据库的适用条件。

## 启用服务

安装科学分析依赖并执行迁移：

```bash
uv sync --locked --group dev --extra model --extra report
uv run --no-sync alembic upgrade head
```

设置 `.env` 的 `CELLLENS_DATA_WORKER_ENABLED=true` 并重启。打开“上传分析”或 `/datasets` 即可使用，无需登录、注册或管理员创建账号。只运行上传表达/代谢分析时，GPU 与 STATE worker 可以关闭。

当前采用共享科研工作区：能访问部署的人可上传、查看、下载数据和结果，也可归档数据集。应用不区分个人身份或提供个人文件权限，应在项目原有的受控科研网络中部署。网页与 `/api` 使用同一来源；跨站浏览器写请求在解析上传内容之前被拒绝，CLI 不需要会话或 CSRF 令牌。

`/api/v1/ready` 仍检查预设 STATE 服务的数据库、GPU 与 worker，因此仅启用 CPU 服务时返回 503。上传分析功能状态见 `/api/v1/data-capabilities`，数据库连通性见 `/api/v1/health`。

`0003_shared_workspace` 使新增数据和任务的 `owner_id` 为空，表示共享记录。旧账号、会话、私有数据记录和源文件保留；旧账号数据不自动公开，也不进入新的共享 CPU 队列。旧账号接口、页面和管理脚本已移除。若需迁入共享区，先明确文件可共享，再由部署维护者导出原 H5AD 并重新上传；不会静默改写旧数据的归属。已有共享记录时，迁移拒绝回退到要求账号归属的旧结构，避免误删或错误归属。

## 上传要求

在 `/datasets` 页面上传 `.h5ad`。一次上传创建独立不可变版本，不覆盖同名数据；保存 SHA-256、参数、来源说明与细胞/基因数。

| 字段 | 内容 |
|---|---|
| 基因 | `var_names` 或 `var.gene_symbol`，使用明确的人类基因符号；存在 `gene_symbol` 时优先使用它 |
| 可选身份 | `var.hgnc_id`；代谢分析复用冻结 HGNC 映射，冲突或歧义不自动合并 |
| 细胞 | 唯一且非空的 `obs_names` |
| 表达矩阵 | `X`，或填写 `layers` 中的具体名称；不使用 `obsm` 嵌入代替表达 |
| 分组 | `obs` 中无缺失且有 2–40 个不同取值的列，例如 condition、sample、cell_type |
| 背景 | 自行填写细胞背景或实验来源，不用于自动证明模型适用性 |

表达值必须有限、非负且尺度明确。原始计数必须为整数。

- `raw_counts` + 完整文库：用户明确确认矩阵包含完整文库后，系统可根据每个细胞的矩阵总计数计算 CP10K；也可提供真实完整文库总计数列。
- `raw_counts` + 筛选面板：必须指定 `obs` 中筛选前的完整文库总计数列，不能把当前面板的行和当作完整文库。
- `cp10k`：用户确认已按完整文库归一化。
- `log1p_cp10k`：用户确认已为 log1p(CP10K)。系统检查其逆变换是否有限，不再按所选面板重新归一化。

不自动猜测表达尺度、不填补缺失基因、不合并重复基因。Ensembl ID 可以用于一般表达探索；代谢分析应另提供 HGNC 符号或明确 HGNC 身份，系统没有通用 Ensembl 转换器。只有两个或以上细胞、两个或以上基因的数据可用于本工作流。

默认限制：单文件 256 MiB、工作区源文件累计 2 GiB（含保留的旧源文件）、10,000 个细胞、60,000 个基因、单个数组或稀疏非零数组 2,000 万个值、HDF5 数组解码预检 512 MiB。数值限制可以通过 `.env.example` 中对应配置调整。上传请求要求 `Content-Length`，同时检查实际读取量；拒绝外部/软 HDF5 链接、循环硬链接与引用对象。网关应配置对应请求体上限。解码预检是数组与元数据大小估计，并非操作系统内存硬限制；该版本仍面向受控科研用户。

## 分析任务

### 表达探索

保存逐细胞检出基因数、CP10K 总和、可用原始文库计数。对完整输入基因计算分组平均 log1p(CP10K) 和检出率；指定参考组时导出“本组平均 − 参考组平均”。这些是描述性统计，没有 p 值、FDR 或因果效应估计；选择细胞而缺乏生物学重复不能替代正式差异分析。

PCA 选择全部输入细胞中方差最高的最多 1,000 个基因，均匀抽取最多 2,000 个细胞进行展示，保存原始细胞标识、种子和解释方差。统计与代谢分析仍使用全部输入细胞；只对可视化进行抽样。常量表达返回零坐标和零解释方差，不编造结构。

### 代谢分析

包含表达探索，并运行 scCellFie 0.6.2。使用完整上传基因面板、冻结人类数据库与固定阈值，保存逐细胞任务/反应评分、分组均值和参考组差值。无需把输入裁成 STATE 的 2,000 个基因。上游会按可用基因筛选可评分任务与反应；页面区分本次返回的评分数和数据库总数，未返回评分的任务不能当作零分。官方完整性报告包含全部任务、反应、覆盖和缺失基因；其数值描述本输入面板相对于数据库的可用范围，不代表准确率或实测通量。

基因符号适配只调整明确身份，不修改或填充表达。失败时记录原因，保留源文件；没有结果的任务不显示完成。CPU 队列持久化排队/运行状态，并以数据库命名锁串行执行；重启后锁持有者可重新执行未完成任务。整个共享工作区最多同时保留三个未完成任务。当前没有任务取消、执行超时和集群资源调度；管理员应按机器资源设置输入上限。

### STATE 兼容性

上传后显示背景是否在注册表中，以及登记基因面板匹配情况和缺少的模型元数据列。当前兼容性检查不意味着已完成模型泛化验证，也不开放自有数据直接驱动 STATE。预设实验仍使用管理员登记的对照数据、模型与许可条件。

## 数据与分析管理

一次上传创建不可变数据版本，保存名称、背景、说明、表达尺度、SHA-256 与创建时间。按名称搜索数据集，选中数据后创建表达探索或代谢任务；分析名称可自行填写，未填写时根据数据集名称和分析类型生成。

一个数据集可以对应多次分析，每次任务记录自己的分组列、参考组和随机种子，不覆盖其他分析。记录列表按创建时间倒序，支持仅当前数据集与状态筛选。排队、运行、完成和失败均在 SQL 中持久化，页面关闭后任务仍继续；结果页地址可在工作区内用于定位和复查。

原始 H5AD 位于 `data/user_uploads/`，结果位于 `data/derived/user_analyses/`，均被 Git 忽略且不通过静态路由公开。受控部署中的共享 API 可下载源文件及完整 CSV/JSON，下载时检查文件 SHA-256；随机编号只用于定位，不构成访问权限。

归档后不能新建分析，原始版本和既有结果继续保留；已经排队的任务不取消。归档不释放存储配额。当前没有永久删除、自动过期清理与集群调度，部署维护者需按科研保留规则备份和管理磁盘。

## API

基础路径 `/api/v1`，完整字段与请求示例见部署后的 `/docs`。

| 接口 | 用途 |
|---|---|
| `GET /data-capabilities` | 科学依赖、CPU 服务状态、格式及资源上限 |
| `POST /datasets` | multipart：`file` 为 H5AD、`metadata` 为上传元数据 JSON 字符串 |
| `GET /datasets` | 分页共享数据集，`limit` / `offset`，`q` 按名称搜索 |
| `GET /datasets/{id}` | 校验信息与来源 |
| `GET /datasets/{id}/file` | 下载原始 H5AD |
| `POST /datasets/{id}/archive` | 归档数据集 |
| `POST /analyses` | 选择 name（可选）、dataset_id、kind（explore/metabolism）、group_key、reference_group、seed |
| `GET /analyses` | 分页共享任务，支持 dataset_id、status 筛选 |
| `GET /analyses/{id}` | 状态、错误、结果文件清单与哈希 |
| `GET /analyses/{id}/report` | 完整分析报告 JSON |
| `GET /analyses/{id}/files/{filename}` | 下载清单中的结果 CSV/JSON |

接口无需账号或会话，数据与结果对工作区共享。写操作检查浏览器来源，上传检查 Content-Length 和实际请求体大小。服务不会接受客户端指定服务器文件路径。
