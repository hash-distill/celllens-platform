# 结果概览与研究工作流

更新日期：2026-10-22。

## 从研究对象到结果

主流程是“查询公开数据 → 直接分析实测 → 按需预测与比较 → 阅读关键变化 → 追溯及导出”。研究分析区分实测 CPU 分析和在线模型预测。结果身份由 `/measured/:analysisId` 或 `/runs/:runId` 固定；修改下一次任务草稿不会改变已完成结果。

主导航为研究分析、记录与比较、数据与方法、使用说明。记录与比较集中提供实测记录、预测记录及预测结果比较。旧 `/demo?run=...` 兼容跳转到真实运行详情；读取历史结果不会重新执行模型。模型下载、服务状态、AI 设置留在辅助入口。

## 概览先回答什么

| 层次 | 内容 | 阅读方式 |
|---|---|---|
| 研究条件 | 背景、目标、来源、实际人数与输入面板 | 先确认是否同一研究对象和群体 |
| 关键变化 | 由已保存表格得到的基因与任务变化 | 变化大小不等于统计显著性 |
| 任务数值 | 选中任务的对照、预测或实测均值及差值 | 实测路径没有预测列；缺失不补零 |
| 解释条件 | 任务关联覆盖、缺失基因和可用比较 | 按关联覆盖率、绝对差值排序；默认前 8 项，可展开本分类全部任务 |
| 专业检查 | 表达/代谢 PCA、UMAP、逐细胞分布 | 按需展开，核对异质性与方法限制 |
| 追溯与导出 | 完整表、GPR、关联、来源和报告 | 回到本次产物复核具体数值 |

任务覆盖优先排序只依据已有覆盖信息，不等于完成面板敏感性验证、批次稳定性检验或可靠性评级。不能把不同任务分数相加称为“整体细胞活性”。实测完整共同面板与模型比较共同面板不同，三组数值必须来自同一比较协议。

## 操作顺序

1. 从数据目录选择背景和目标；已有实测优先直接分析，无实测且模型支持时可进行明确标注的探索预测。
2. 完成后先看关键变化和所选任务数值，再检查基因、任务全表；ALDOA 不在当前预测输出面板，不能从预测读取其自身变化。
3. 需要判断模型表现时，查看有匹配观测的比较及不变化基线，保留没有改善的结果。
4. 在代谢详情查看变化反应和基因，并展开完整 GPR 或导出关联；简化显示的变化成员不是全部机制。
5. 有需要时展开 PCA/UMAP 和分布，确认单位、群体人数、共同面板和抽样说明。
6. 在 AI 侧栏预览本次摘要后请求辅助讲解，再下载报告或完整表格。

## 科学边界

- 实测是观测 RNA；预测是 STATE 输出；scCellFie 分数是表达派生的功能支持，不是代谢通量、ATP 产量或浓度。
- 均值差不是显著性检验或因果效应；预测样本数量不是新增生物学重复。
- PCA/UMAP 每点表示细胞特征记录，坐标不表示形态、物理位置或同一细胞的前后轨迹。二维重叠或分离不是准确性证明，不同运行独立拟合坐标不可直接叠加。
- 任务—反应—基因关系来自冻结知识库；当前不提供经验证的驱动归因。主流程采用任务详情与关联列表，不宣称三维节点布局为细胞结构。
- 覆盖不是准确率；essential 空集合完整性也不能当作充分生物学支持。
- 旧记录缺少投影、关联或比较时显示原因，不拿其他运行补齐。历史原文件保持自己的版本和哈希。
- 匹配诊断尚未证明训练排除；工程运行与 AI 受控协议测试均不能代替独立生物学评价。
