# 扰动响应工作台：改造与创新说明

更新：2026-10-10。

## 产品主线

CellLens 将一次基因扰动组织为“单细胞状态分布 → 基因响应 → 代谢功能 → 关联依据 → 后续实验线索”。工作台先比较对照和扰动后预测的单细胞表达状态，再展示群体表达差值和任务分数差值。无运行时介绍流程，不填入替代数据。

独立首页 `/` 说明产品与研究流程；工作台 URL `/workbench?run=<run_id>` 固定当前结果身份。上方是横向实验设置，查看结果时默认折叠，复用参数可展开下一次实验的草稿。实验记录 `/records` 从服务器分页检索历史运行，实验比较与结果解读由统一顶部导航进入。修改目标基因不会修改当前结果标题或数值。运行完成后读取真实产物，运行中使用后端阶段进度，单块失败可单独重试。

## 已实现的差异化功能

| 功能 | 实现 | 用户价值 |
|---|---|---|
| 单细胞状态比较 | 对照拟合的共同 PCA、逐细胞基因/任务着色与累积分布；可导出科研图 | 保留单细胞层面的分布信息，避免只看均值 |
| 表达与功能联读 | 变化排序、点击选中基因、对照/预测/差值；任务选择联动解释 | 从数千个表达数值定位候选功能变化 |
| 覆盖约束 | 官方任务/反应完整性、缺失基因、影响加权完整性；各类分数独立色标 | 区分变化幅度与数据支持程度 |
| 冻结解释链 | 运行时保存 task_trace.json；含任务分类、反应、关联基因和真实运行数值 | 每条关联可复查其来源，旧运行不套用新知识库 |
| 三维功能网络 | 可选空间视图；任务、反应、基因分层，点击反应联动列表 | 交互探索功能组成关系，保留可读的数值详情 |
| 解读与分析一致 | 同一 run_id 驱动四章结果解读与工作台各结果页签 | 解读内容与分析结果一致，可从讲解返回证据 |

上述是软件工作流、数据契约与可视化集成创新，不代表重新提出或训练了 STATE/scCellFie。

## 如何使用

1. 从首页进入实验工作台，选择四种背景之一与支持的扰动，点击开始实验；也可在独立实验记录页检索或输入编号打开已有实验。
2. 完成后，先查看响应概览，再从“单细胞状态”比较共同 PCA 与累积分布；在基因和代谢页选择指标、检查变化与完整性并追溯关联。
3. 在追溯区域选择反应，右侧显示关联基因及其表达变化。缺少面板基因时保留知识关联，数值为“未提供”。
4. 点击“探索三维功能网络”，拖动旋转、滚轮缩放；点击反应节点联动详情。为避免拥挤，空间视图最多显示 8 个反应、每个反应 10 个基因，实际数量会显示在图下注释。API 截断另有提示。
5. 展开“查看追溯来源”或运行来源区域，检查数据库版本、哈希和运行编号。
6. 工作台页签保留表格与验证，本次实验栏提供比较和报告；细胞器结构示意已移除。

## 科学含义与限制

- STATE 的 ST 模型以对照细胞集合和扰动条件为输入，预测扰动后细胞群体；其自注意力建模单细胞异质性。这里的“状态”是转录组表达状态，不是细胞器几何形态。[STATE 论文图 1、方法 4.3](https://www.biorxiv.org/content/10.1101/2025.06.26.661135v2.full)
- 论文训练时按细胞背景、可选批次采样对照集合，并不要求同一个物理细胞的前后实测配对。页面不按 cell_index 连线，不将预测点当作真实纵向轨迹。
- 四背景当前活跃模型均在 2000 基因 `X_hvg` 空间推理，未使用 SE 嵌入。单细胞主图基于本次对照拟合 PCA，各来源共享该变换，并提供基因/任务着色和累积分布；坐标不表示物理位置。
- 点数按投影产物实际显示数量统计；抽样点数不是完整群体数量或细胞比例。没有观测点时不补数据，合成模式显式标注；二维分离或重叠本身不证明预测正确。
- STATE 输出可同时包含目标扰动和模拟对照。新版分析先按登记的扰动列筛选目标群体，再生成表达、投影、代谢及追溯产物；投影保存 `population_selection` 数量与协议记录。旧在线分析缺少该记录时显示明确警告，已有产物不被覆盖，须新建运行核验。
- 表达差值不是统计显著性；反应/任务分数不是通量、ATP 产量或代谢物浓度。
- 基因—反应连线来自知识库。当前不提供评分决定基因的归因；关联不是因果贡献。
- 空间网络的坐标是展示布局，不是细胞器位置、实测形态或生理轨迹；不使用粒子速度表示通量。
- 覆盖支持表示通过既有覆盖门槛，不是准确率、置信概率或生物学验证。
- 旧运行或合成包没有 task_trace.json 时保留已有结果，并明确显示关联追溯不可用；不会自动重新解释或覆盖原始产物。
- 正式生物学泛化评价仍需独立完成。

单细胞分布读数与共同对照 PCA 已实现，协议、输入哈希和导出元数据可复核。对未见扰动的高维分布泛化评价仍需独立协议；SE 实验资产尚未替换当前活跃模型。

## 工程入口

- 首页：`frontend/src/views/HomeView.vue`。
- 统一工作台：`frontend/src/views/WorkbenchView.vue`。
- 历史实验：`frontend/src/views/RecordsView.vue`，读取 `GET /api/v1/runs`。
- 双视图：`frontend/src/components/response/ResponseWorkspace.vue`。
- 关联列表与三维网络：同目录 `TaskTrace.vue`、`TraceNetwork.vue`。
- 冻结产物：`backend/app/services/task_trace.py`，由 `scientific_analysis.py` 在运行中写入。
- API：`GET /api/v1/runs/{run_id}/task-trace?task_id=...`；只读取该运行已校验的产物。
- 浏览器验收：`python scripts/check_response_frontend.py --url http://127.0.0.1:8000 --run-id <含追溯产物的已完成运行>`。

测试和实际运行记录见 [2026-10-08 验收记录](../verification/2026-10-08-response-workbench.md)。
