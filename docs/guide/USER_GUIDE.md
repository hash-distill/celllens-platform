# CellLens 使用指南

说明实验设置、结果阅读与导出流程。更新日期：2026-10-10。

## 1. 一次运行要回答什么

> 在指定细胞背景下，干预某个基因，其他基因表达和代谢功能预计怎样变化？

系统先用 STATE 生成预测表达，再用 scCellFie 将表达转成反应、代谢任务分数。结果帮助提出待验证的实验线索。

## 2. 参数是什么意思

| 参数 | 含义 | 初次使用 |
|---|---|---|
| 细胞背景 | 研究哪类细胞；决定使用的模型与对照数据 | K562 |
| 扰动基因 | 本次预测的干预目标 | 从当前模式的支持列表选择 MYC |
| 运行模式 | 执行新预测、读取保存结果或与匹配实测比较 | 在线推演 |
| 虚拟样本量 | 请求生成的预测表达记录数 | 页面默认 64；可设 64–4,096 |
| 随机种子 | 控制随机抽样，便于复查参数 | 保持 42 |

K562 是一种实验研究用的人类细胞系，来源于慢性髓性白血病。这里比较的是单细胞表达状态。[ATCC](https://www.atcc.org/products/ccl-243)

当前所用 Replogle 数据的干预主要是 CRISPRi：抑制目标基因表达。可以理解为降低这个基因的使用程度，不应一概称为删除或完全敲除基因。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9380471/)

MYC 是可选的在线扰动目标之一。它编码调节基因表达的蛋白质，参与细胞周期等过程；选择 MYC 并不预先保证任何特定预测结论。[NCBI](https://www.ncbi.nlm.nih.gov/gtr/genes/4609/)

当前在线推演支持 K562、RPE1、Jurkat、HepG2。每种背景使用对应的实测对照与官方模型；切换背景后需重新选择扰动。模式能否运行以页面的服务与资产状态为准。样本量增加不会自动提高模型准确性。

## 3. 完成一次在线预测

1. 按 [部署文档](../DEPLOYMENT.md) 启动系统，进入 `/` 首页，再从顶部打开“实验工作台”。
2. 选择 K562 与在线推演，在下拉列表中选择目标基因。
3. 打开高级参数，确认样本量（页面默认 64）和 seed=42，点击“开始实验”。
4. 记录运行编号，等待完成；出现警告时查看原因。
5. 工作台保持本次运行编号；从“代谢功能 → 功能前后对比”筛选任务，比较分数和变化量，点击节点查看证据。单细胞状态提供共同 PCA、逐细胞着色和累积分布科研图。
6. 选中关联反应查看全部基因与 GPR 规则，检查官方完整性；有实测时切换“预测与实测”。可导出关联 JSON，或在本次实验栏导出报告。[详细操作](FUNCTION_WORKSPACE.md)。

不支持任意文本基因、双基因干预或自定义药物剂量。在线推演是模型推理，不是重新训练；计算位置由后端部署位置决定。

同一请求可能复用已有缓存。如果返回 `cache_hit=true`，说明读取的是匹配的已有运行，而不是又执行了一次模型推理。

## 4. 按顺序阅读结果

| 区域 | 应该看什么 | 解释边界 |
|---|---|---|
| 本次参数与进度 | 背景、目标、模式、运行编号、警告 | 完成表示流程完成 |
| 代谢功能 → 功能前后对比 | 同布局对照/预测、变化量、有观测时的预测/实测；关联反应、基因与 GPR | 分数不是通量；连线仅为知识库关联；覆盖不是准确率 |
| 单细胞状态 | A 共同 PCA、B 基因/任务着色、C 逐细胞累积分布，支持科研图导出 | 解释方差不是准确率；不是形态或逐点配对；详见 [科研图说明](SCIENTIFIC_CELL_STATE.md) |
| 基因响应 | 预测相对对照的变化方向与大小 | 当前差值不是显著性检验结果 |
| 代谢功能 → 任务分数与数据覆盖 | 完整任务分数变化与覆盖比例 | 分数不是通量、ATP 产量或浓度 |
| 预测验证 | 是否有匹配观测与有效比较 | 在线模式不提供匹配观测；训练排除关系未核实，指标限于匹配观测比较 |
| 来源信息 | 模型、数据、数据库和哈希 | 用于追溯本次结果 |

覆盖等级 `supported` 表示通过项目定义的基因覆盖门槛，不代表预测已被实验验证。先看覆盖与警告，再讨论分数变化。

scCellFie 使用 STATE 的预测表达时，会继承输入预测的不确定性；功能解释不能独立证明表达预测准确。

## 5. 实验记录、比较与结果解读

顶部“实验记录”是独立的历史实验页面，读取服务器数据库，按创建时间倒序展示背景、目标、来源、状态和运行编号。支持目标或编号检索、状态与来源筛选、分页；刷新页面或换浏览器仍可读取服务器记录。点击“打开分析”返回绑定该实验的工作台，也可输入运行编号直接打开。

在记录列表或工作台点击“加入比较”，再从顶部打开“实验比较”。比较候选保存在当前浏览器，最多四个；选择前应核对背景、来源与模型版本。每列的“移出比较”可删除单个候选，页顶的“清空比较”可移出全部候选，刷新后仍保留操作结果。移出不会删除实验记录或结果文件；点击“选择实验”可回到实验记录重新加入其他实验。

工作台内的三维功能网络读取本次冻结的任务—反应—基因关联；点击反应同步数值详情，拖动旋转、滚轮缩放。坐标是展示布局，连线不是因果贡献。旧运行没有追溯产物时明确提示不可用。产品已删除细胞器结构示意。

运行完成后点击“解读本次实验”，或从顶部“结果解读”打开当前实验的四章讲解。自动播放每章 10 秒，有进度与倒计时；这是一组分析章节，不是连续生理过程模拟。

## 6. 其他模式

- **结果回放**：四背景均可选择 ALDOA，读取真实 STATE/scCellFie 结果及实测对照；页面提示“真实结果回放（本次未重新计算）”，证据栏可进入原始运行。样本量和 seed 不改变已保存数据。正式运行目录只提供真实模型结果；历史合成记录保留明确的来源标记。
- **实测对照**：四背景均开放，当前只可选择 ALDOA。执行新的预测并与登记观测比较，展示表达误差、差异基因、代谢任务及“不发生扰动”基线。训练排除尚未核实、观测细胞数量有限，不能当作正式留出验收。其他基因可使用在线推演，尚无匹配诊断入口。

初次查看各背景可选择“结果回放 → ALDOA”，立即打开保存结果，再点击“解读本次实验”。四章讲解读取所选背景的实际结果。2026-10-09 这组样本诊断中 HepG2 的表达 MSE 高于不变化基线；功能可用不等于该模型在所有背景都预测准确。完整数值及范围见 [四背景能力验收](../verification/2026-10-09-four-context-capabilities.md)。

## 7. 下一次实验

先保持背景、样本量和种子一致，换一个支持列表中的基因，再将两次运行加入候选进行描述性比较。调整“下一次实验”的草稿不会改变已经完成的运行结果。

进一步了解方法，阅读 [STATE 与 scCellFie 模型说明](MODELS.md)。
