# CellLens 使用指南

说明实测分析、预测设置、结果阅读与导出流程。更新日期：2026-10-23。

顶部“研究分析”进入统一实验设置页（`/research`），在“实验类型”中选择“实测分析”或“模型预测”。切换类型保留细胞背景与扰动基因，采样参数分别保存；实测分析默认使用 CPU，模型预测按服务就绪情况开放。旧 `/measured` 和 `/workbench` 设置链接仍可打开对应类型。

两种实验都使用相同的细胞背景单选卡片、基因功能分类和可搜索候选框。选择分类后从对应候选中选取基因，也可搜索基因符号或已有的中英文名称；支持上下方向键和回车选择。切换细胞背景会重置分类与基因。分类计数分别基于当前背景的实测候选或模型支持候选，两种实验的候选数量可以不同。

## 先查数据，优先分析实测

从“数据与方法”进入数据目录，按背景和目标查询。已有实测时点“直接分析实测”，无需下载模型或启用 GPU；设置真实细胞上限后，查看实际批次匹配人数、共同基因、表达均值差、PCA/UMAP 和可用功能分数。本源有记录但本地未下载时，提交后按需读取相应真实细胞。实测分析位于 `/measured`，实测历史由“实验记录”的类别筛选（`/records?category=measured`）进入，可导出完整 CSV、投影 JSON、HTML 或 ZIP。详见[实测分析说明](../MEASURED_ANALYSIS.md)。

已有实测也可明确运行预测并做对比；本源无记录且模型支持时只能进行探索预测。当前模型支持四背景和 2,023 个非对照目标，未证明未知细胞或词表外基因泛化；完整数据缺口与证据见[泛化说明](../GENERALIZATION.md)。下面的“采样细胞数”和 STATE 流程专指模型预测；实测分析不会复制观测以补齐请求数。


## 1. 一次预测要回答什么

> 在指定细胞背景下，干预某个基因，其他基因表达和代谢功能预计怎样变化？

系统先用 STATE 生成预测表达，再用 scCellFie 将表达转成反应、代谢任务分数。结果帮助提出待验证的实验线索。

## 2. 参数是什么意思

| 参数 | 含义 | 初次使用 |
|---|---|---|
| 细胞背景 | 研究哪类细胞；决定使用的模型与对照数据 | K562 |
| 扰动基因 | 本次预测的干预目标 | 从当前背景的在线支持列表选择 MYC |
| 预测采样细胞数 | 请求生成的预测表达记录数，不改变真实对照数量 | 页面默认 64；可设 64–4,096 |
| 随机种子 | 控制本次模型取样，便于复查；不重抽已保存的真实对照文件 | 保持 42 |

K562 是一种实验研究用的人类细胞系，来源于慢性髓性白血病。这里比较的是单细胞表达状态。[ATCC](https://www.atcc.org/products/ccl-243)

当前所用 Replogle 数据的干预主要是 CRISPRi：抑制目标基因表达。可以理解为降低这个基因的使用程度，不应一概称为删除或完全敲除基因。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9380471/)

MYC 是可选的在线扰动目标之一。它编码调节基因表达的蛋白质，参与细胞周期等过程；选择 MYC 并不预先保证任何特定预测结论。[NCBI](https://www.ncbi.nlm.nih.gov/gtr/genes/4609/)

当前在线推演支持 K562、RPE1、Jurkat、HepG2。每种背景使用对应的实测对照与官方模型；切换背景后需重新选择扰动。在线推演能否运行以页面的服务与资产状态为准。样本量增加不会自动提高模型准确性。

首次部署缺少权重时，先打开右上角连接服务入口，在“按需准备细胞背景”中只选择需要的背景下载。许可确认、进度、取消和重试均在该页面；准备后工作台刷新可用状态。新提取对照最多 1,024 个，已有合法对照继续复用，实际人数以页面核验为准。详见[资源管理](../INFERENCE_RESOURCES.md)。

在“数据与方法 → 细胞背景”查看各背景的真实对照数量、non-targeting 阴性对照含义、公开来源和预测取样方式，并可展开生物学背景。工作台参数旁的“了解对照与采样”直接链接到对应说明。

当前 K562、RPE1、Jurkat、HepG2 的新任务均使用 1024 个实测细胞的登记对照池；这些是本地数据准备时选取并保存的样本，不是公开数据集全部细胞，也不是每次实验新生成的。共同批次筛选后的实际人数可以减少。K562 原 3000 个对照保留用于历史结果，旧分析不会自动改算。页面从哈希有效的对照文件读取 obs 元数据核对数量；无法核验时不显示假定人数。

64–4096 是平台请求范围，不是独立实测样本数或模型准确性等级。STATE 以有放回方式从对照池取样，再预测目标扰动表达，所以预测记录可以多于真实对照。重复使用对照状态不会增加独立生物学样本；预测与对照以群体均值和分布比较，不要求等量，也不逐一配对。散点数量/疏密受样本量影响，不能直接解释为增殖、死亡或更强的扰动。采样行为同时核对了当前安装的 arc-state 0.11.1 与[官方实现](https://github.com/ArcInstitute/state/blob/main/src/state/_cli/_tx/_infer.py)。

| 背景 | 中文类型 | English type | 参考来源 |
|---|---|---|---|
| K562 | 髓系白血病细胞系，悬浮生长 | Myeloid leukemia cell line; suspension | [Cellosaurus CVCL_0004](https://www.cellosaurus.org/CVCL_0004) |
| RPE1 | hTERT 永生化视网膜色素上皮细胞系，贴壁生长 | hTERT-immortalized retinal pigment epithelial cell line; adherent | [Cellosaurus CVCL_4388](https://www.cellosaurus.org/CVCL_4388) |
| Jurkat | T 淋巴细胞白血病细胞系，悬浮生长 | T-cell leukemia cell line; suspension | [Cellosaurus CVCL_0065](https://www.cellosaurus.org/CVCL_0065) |
| HepG2 | 肝母细胞瘤来源细胞系，贴壁生长 | Hepatoblastoma-derived cell line; adherent | [Cellosaurus CVCL_0027](https://www.cellosaurus.org/CVCL_0027) |

HepG2 采用 Cellosaurus 根据后续研究修正的肿瘤来源分类。介绍描述细胞系的一般特征，不将公共目录中的亚克隆信息直接认定为当前数据所用的亚克隆；具体来源与处理条件需结合实验数据追溯。

## 3. 完成一次在线预测

1. 按 [部署文档](../DEPLOYMENT.md) 启动系统，进入 `/` 首页，再打开“研究分析”的模型预测任务。
2. 选择 K562 背景，可先按蛋白功能类别筛选，再搜索和选择目标基因。类别和说明提供中英文，采用 PANTHER 蛋白功能分类；无注释时保留“暂无分类注释”。筛选不会改变模型支持的扰动范围。
3. 在细胞背景下方确认预测采样细胞数（页面默认 64）和 seed=42，点击“开始实验”。
4. 记录运行编号，等待完成；出现警告时查看原因。
5. 工作台保持本次运行编号；结果详情位于 `/runs/:runId`。响应概览先显示关键基因、任务变化及所选任务的对照/预测/可用实测数值；PCA/UMAP 专业检查按需展开。从“代谢功能”查看任务分数分布及关联依据。
6. 选中任务检查反应、关联基因、完整 GPR 和缺失成员；简化视图只突出变化成员，完整关联以展开内容与导出为准。有匹配实测时打开“预测与实测”，核对同一比较群体和面板。可导出关联 JSON 或报告。[详细操作](FUNCTION_WORKSPACE.md)。

不支持任意文本基因、双基因干预或自定义药物剂量。在线推演是模型推理，不是重新训练；计算位置由后端部署位置决定。

同一请求可能复用已有缓存。如果返回 `cache_hit=true`，说明读取的是匹配的已有运行，而不是又执行了一次模型推理。

## 4. 按顺序阅读结果

| 区域 | 应该看什么 | 解释边界 |
|---|---|---|
| 本次参数与进度 | 背景、目标、模式、运行编号、警告 | 完成表示流程完成 |
| 代谢功能 → 功能前后对比 | 同布局对照/预测、变化量、有观测时的预测/实测；关联反应、基因与 GPR | 分数不是通量；连线仅为知识库关联；覆盖不是准确率 |
| 表达状态分布 | A 共同 PCA、B 基因/任务着色、C 逐细胞累积分布，支持科研图导出 | 每点一个细胞，坐标表示表达特征差异；点云不是形态、物理位置或前后配对轨迹；详见 [状态分布说明](SCIENTIFIC_CELL_STATE.md) |
| 基因响应 | 预测相对对照的变化方向与大小 | 当前差值不是显著性检验结果 |
| 代谢功能 → 任务与反应分数 | 完整有效的任务与反应分数变化 | 分数不是通量、ATP 产量或浓度 |
| 预测与实测 | 是否有匹配观测、有效比较及不变化基线 | 比较独立准备，不改写原预测；训练排除未核实，不能称独立验证 |
| 来源信息 | 模型、数据、数据库和哈希 | 用于追溯本次结果 |

概览按任务关联基因覆盖率优先、绝对差值其次排序，默认前 8 项，可展开本分类全部任务。任务详情保留对照、预测或实测的实际数值；完整实测结果与预测比较的共同子集不能直接混为同一群体。该展示排序不是可靠性、显著性或机制认证。

每次实验的概览和代谢结果集中显示本次变化。覆盖统计与基因、任务清单集中在独立的“模型覆盖范围”页面；实验页提供查看其实际输入范围的入口。覆盖不代表预测已被实验验证。

scCellFie 使用 STATE 的预测表达时，会继承输入预测的不确定性；功能解释不能独立证明表达预测准确。

## 5. 实验记录、比较与结果解读

顶部“实验记录”（`/records`）将实测分析与模型预测合并为一张表，按创建时间倒序排列，支持类别、状态、关键词筛选与统一分页。原实测历史链接仍兼容。顶部“结果解读”（`/records?view=results`）只展示已完成结果，也可按类别筛选。记录操作统一为“结果解读”；未完成记录不提供可用的解读按钮，可点击实验名称查看状态。实测详情进入 `/measured/:analysisId`，预测详情进入 `/runs/:runId`，均保留各自来源、背景、目标与编号。

在预测结果页点击“加入比较”，再进入“结果解读”的“预测结果比较”页签。比较候选保存在当前浏览器，最多四个；选择前应核对背景、来源与模型版本。每列的“移出比较”可删除单个候选，页顶的“清空比较”可移出全部候选，刷新后仍保留操作结果。移出不会删除实验记录或结果文件；点击“选择实验”可回到实验记录，打开已完成的预测结果后加入其他实验。

任务详情读取本次冻结的任务—反应—基因关联，变化成员可突出展示，完整关联与 GPR 可复核或导出。知识关联不是因果贡献。旧运行没有追溯产物时明确提示不可用；当前主流程不以三维网络或细胞器结构表达科学结论。

运行完成后打开当前结果，查看响应概览、表达状态分布、基因响应与代谢功能，并可下载报告。旧 `/demo?run=...` 链接跳转到对应预测详情；未选择实验时从历史记录选择，不新建回放任务。

顶栏右侧提供亮暗切换和服务连接入口，点击连接状态可进入服务状态页。右侧快捷栏提供 AI 解读、模型设置、直达顶部、直达底部和使用说明。先在模型设置填写提供商、模型与 API Key；打开已完成结果，选择任务与补充问题，预览后发送摘要。实测支持概要、基因、代谢、覆盖和后续建议；预测还支持科研图与匹配比较解读。切换图表自动清除旧解读；生成文本可下载保存。

基因、代谢任务、关联反应、覆盖目录的结果分页默认每页 20 条，可选择 10、20、50 或 100 条。切换条数或筛选条件会回到第一页；下载仍包含完整的已保存结果。

从“数据与方法”进入“02 细胞背景”（`/methods/backgrounds`），查看生物学背景、表达面板、可选扰动和登记实测；进入“03 覆盖范围”（`/methods/coverage`）浏览代谢覆盖数量和清单。相同面板与数据库的覆盖范围合并展示，页内列出适用背景；模型权重、对照和实测数据仍按背景分别登记。原首页覆盖卡片已移除。可以切换细胞背景、按科学功能类别筛选已覆盖的代谢基因，并搜索基因符号、英文名称或 HGNC ID。类别提供中英文说明，允许同一基因有多个功能类别，类别计数不能相加作为总数。

“代谢任务介绍”展示任务的中英文名称、生物学作用、关联基因与解读范围；完整覆盖的七项精细介绍还区分局部步骤和整个通路。基因 CSV 保留覆盖基因；覆盖目录 JSON 保留覆盖基因、完整/部分覆盖任务及全部源反应条目以解析引用，并注明数量与纳入规则；原始全数据库完整性报告仍作为实验产物保留。

目录从已校验的模型基因面板与冻结数据库生成。同一面板和数据库下，范围不随扰动目标、样本量或种子改变；更换面板或数据库会重新计算。历史入口 `/coverage?run=...` 会保留参数跳转到 `/methods/coverage?run=...`，使用该实验保存的输入范围，历史模型不套用当前在线模型的统计。

## 6. 查看历史实验

从“实验记录”检索并直接打开已有结果，读取过程不重新计算或新增任务。历史记录保留原参数、来源与观测比较文件；复用参数会进入新的在线推演草稿。新建实验不再提供结果回放或实测对照模式。


## 7. 下一次实验

先保持背景、样本量和种子一致，换一个支持列表中的基因，再将两次运行加入候选进行描述性比较。调整“下一次实验”的草稿不会改变已经完成的运行结果。

进一步了解方法，阅读 [STATE 与 scCellFie 模型说明](MODELS.md)。

已完成实验可从顶部下载分析、单细胞、网络或基因排序结果包；表格的完整 CSV 不受分页或非零行筛选影响。原分析群体与匹配实测诊断分开标注，H5AD 为 log1p(CP10K) 而非原始计数。内容与外部工具读取方法见[导出与外部工具](EXPORTS.md)。

## 8. 服务状态

点击顶部连接状态进入独立“服务状态”页。进入页面时采集后端主机的数据库引擎与版本、连接延迟和连接池、NVIDIA GPU 型号、驱动、显存、利用率与温度，以及 CPU、内存、磁盘、操作系统、Python 与科学计算包版本。内存、磁盘和 GPU 使用以进度条展示；页面不定时刷新，点击“重新检查”重新采集。采集不到的硬件信息显示“未获取”。

分析服务分别显示配置是否启用、本进程的运行状态以及待完成任务数；无法检测的字段显示未获取，不推断为正常或零。GPU 信息来自 nvidia-smi；页面展示当前部署的主机，不代表其他远端计算机。

“模型方法”（`/methods/models`）介绍 STATE 与 scCellFie 的输入、输出和系统中的作用，包含流程示意图及官方来源。“细胞背景”的表达面板可以搜索与下载；“覆盖范围”提供代谢基因和任务目录，代谢任务可按完整覆盖、部分覆盖、未覆盖或全部数据库任务筛选，详情列出可用和缺失基因。可选扰动目标、预测表达面板与代谢关联基因是不同集合。
