# CellLens 使用指南

说明实验设置、结果阅读与导出流程。更新日期：2026-10-11。


## 1. 一次运行要回答什么

> 在指定细胞背景下，干预某个基因，其他基因表达和代谢功能预计怎样变化？

系统先用 STATE 生成预测表达，再用 scCellFie 将表达转成反应、代谢任务分数。结果帮助提出待验证的实验线索。

## 2. 参数是什么意思

| 参数 | 含义 | 初次使用 |
|---|---|---|
| 细胞背景 | 研究哪类细胞；决定使用的模型与对照数据 | K562 |
| 扰动基因 | 本次预测的干预目标 | 从当前背景的在线支持列表选择 MYC |
| 虚拟样本量 | 请求生成的预测表达记录数 | 页面默认 64；可设 64–4,096 |
| 随机种子 | 控制随机抽样，便于复查参数 | 保持 42 |

K562 是一种实验研究用的人类细胞系，来源于慢性髓性白血病。这里比较的是单细胞表达状态。[ATCC](https://www.atcc.org/products/ccl-243)

当前所用 Replogle 数据的干预主要是 CRISPRi：抑制目标基因表达。可以理解为降低这个基因的使用程度，不应一概称为删除或完全敲除基因。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9380471/)

MYC 是可选的在线扰动目标之一。它编码调节基因表达的蛋白质，参与细胞周期等过程；选择 MYC 并不预先保证任何特定预测结论。[NCBI](https://www.ncbi.nlm.nih.gov/gtr/genes/4609/)

当前在线推演支持 K562、RPE1、Jurkat、HepG2。每种背景使用对应的实测对照与官方模型；切换背景后需重新选择扰动。在线推演能否运行以页面的服务与资产状态为准。样本量增加不会自动提高模型准确性。

实验台选择背景后会显示对应细胞系的中英文来源介绍，展开“特点与研究用途”可阅读生物学特点及常见应用。“模型覆盖范围”页面提供当前背景的完整介绍，以及可展开的四背景对照。

| 背景 | 中文类型 | English type | 参考来源 |
|---|---|---|---|
| K562 | 髓系白血病细胞系，悬浮生长 | Myeloid leukemia cell line; suspension | [Cellosaurus CVCL_0004](https://www.cellosaurus.org/CVCL_0004) |
| RPE1 | hTERT 永生化视网膜色素上皮细胞系，贴壁生长 | hTERT-immortalized retinal pigment epithelial cell line; adherent | [Cellosaurus CVCL_4388](https://www.cellosaurus.org/CVCL_4388) |
| Jurkat | T 淋巴细胞白血病细胞系，悬浮生长 | T-cell leukemia cell line; suspension | [Cellosaurus CVCL_0065](https://www.cellosaurus.org/CVCL_0065) |
| HepG2 | 肝母细胞瘤来源细胞系，贴壁生长 | Hepatoblastoma-derived cell line; adherent | [Cellosaurus CVCL_0027](https://www.cellosaurus.org/CVCL_0027) |

HepG2 采用 Cellosaurus 根据后续研究修正的肿瘤来源分类。介绍描述细胞系的一般特征，不将公共目录中的亚克隆信息直接认定为当前数据所用的亚克隆；具体来源与处理条件需结合实验数据追溯。

## 3. 完成一次在线预测

1. 按 [部署文档](../DEPLOYMENT.md) 启动系统，进入 `/` 首页，再从顶部打开“实验工作台”。
2. 选择 K562 背景，可先按蛋白功能类别筛选，再搜索和选择目标基因。类别和说明提供中英文，采用 PANTHER 蛋白功能分类；无注释时保留“暂无分类注释”。筛选不会改变模型支持的扰动范围。
3. 打开高级参数，确认样本量（页面默认 64）和 seed=42，点击“开始实验”。
4. 记录运行编号，等待完成；出现警告时查看原因。
5. 工作台保持本次运行编号；响应概览默认展开共同 UMAP 科研图。“单细胞状态”提供对照参考 PCA、逐细胞着色和累积分布。从“代谢功能 → 功能前后对比”筛选任务，比较分数和变化量，点击节点查看证据。
6. 选中关联反应查看全部基因与 GPR 规则；需要查看缺失基因时打开覆盖范围链接，有实测时切换“预测与实测”。可导出关联 JSON，或在本次实验栏导出 PDF 报告。[详细操作](FUNCTION_WORKSPACE.md)。

不支持任意文本基因、双基因干预或自定义药物剂量。在线推演是模型推理，不是重新训练；计算位置由后端部署位置决定。

同一请求可能复用已有缓存。如果返回 `cache_hit=true`，说明读取的是匹配的已有运行，而不是又执行了一次模型推理。

## 4. 按顺序阅读结果

| 区域 | 应该看什么 | 解释边界 |
|---|---|---|
| 本次参数与进度 | 背景、目标、模式、运行编号、警告 | 完成表示流程完成 |
| 代谢功能 → 功能前后对比 | 同布局对照/预测、变化量、有观测时的预测/实测；关联反应、基因与 GPR | 分数不是通量；连线仅为知识库关联；覆盖不是准确率 |
| 单细胞状态 | A 共同 PCA、B 基因/任务着色、C 逐细胞累积分布，支持科研图导出 | 解释方差不是准确率；不是形态或逐点配对；详见 [科研图说明](SCIENTIFIC_CELL_STATE.md) |
| 基因响应 | 预测相对对照的变化方向与大小 | 当前差值不是显著性检验结果 |
| 代谢功能 → 任务与反应分数 | 完整有效的任务与反应分数变化 | 分数不是通量、ATP 产量或浓度 |
| 预测验证 | 是否有匹配观测与有效比较 | 在线模式不提供匹配观测；训练排除关系未核实，指标限于匹配观测比较 |
| 来源信息 | 模型、数据、数据库和哈希 | 用于追溯本次结果 |

每次实验的概览和代谢结果集中显示本次变化。覆盖统计与基因、任务清单集中在独立的“模型覆盖范围”页面；实验页提供查看其实际输入范围的入口。覆盖不代表预测已被实验验证。

scCellFie 使用 STATE 的预测表达时，会继承输入预测的不确定性；功能解释不能独立证明表达预测准确。

## 5. 实验记录、比较与结果解读

顶部“实验记录”读取服务器数据库，展示在线扰动实验，按创建时间倒序排列。支持细胞背景、扰动基因或编号检索、状态筛选和分页。点击“实验分析”直接打开对应实验的结果解读页。结果页显示本次实验名称与编号。

在记录列表或工作台点击“加入比较”，再从顶部打开“实验比较”。比较候选保存在当前浏览器，最多四个；选择前应核对背景、来源与模型版本。每列的“移出比较”可删除单个候选，页顶的“清空比较”可移出全部候选，刷新后仍保留操作结果。移出不会删除实验记录或结果文件；点击“选择实验”可回到实验记录重新加入其他实验。

工作台内的三维功能网络读取本次冻结的任务—反应—基因关联；点击反应同步数值详情，拖动旋转、滚轮缩放。坐标是展示布局，连线不是因果贡献。旧运行没有追溯产物时明确提示不可用。产品已删除细胞器结构示意。

运行完成后点击“解读本次实验”，或从顶部“结果解读”打开当前实验。直接查看响应概览、单细胞状态、基因响应与代谢功能，并可下载报告。大模型解读统一从右下角“AI 解读”悬浮框打开，跟随当前实验，先预览摘要再手动生成；收起后再次展开保留当前解读，切换实验时清空旧内容。未选择实验时，页面引导从实验记录选择。

基因、代谢任务、关联反应、覆盖目录的结果分页默认每页 20 条，可选择 10、20、50 或 100 条。切换条数或筛选条件会回到第一页；下载仍包含完整的已保存结果。

首页“当前模型覆盖哪些代谢基因与任务？”打开 `/coverage`，只展示当前已覆盖数量和清单。可以切换细胞背景、按科学功能类别筛选已覆盖的代谢基因，并搜索基因符号、英文名称或 HGNC ID。类别提供中英文说明，允许同一基因有多个功能类别，类别计数不能相加作为总数。

“代谢任务介绍”展示目前完整覆盖任务的中英文名称、生物学作用、关联基因、解读范围及 UniProt 来源。当前七项介绍区分数据库映射的局部步骤和整个生物通路。下载已覆盖基因 CSV 或当前覆盖目录 JSON 仅包含当前覆盖项；原始全数据库完整性报告仍作为实验产物保留。

目录从已校验的模型基因面板与冻结数据库生成。同一面板和数据库下，范围不随扰动目标、样本量或种子改变；更换面板或数据库会重新计算。实验入口 `/coverage?run=...` 使用该实验保存的输入范围，历史模型不套用当前在线模型的统计。

## 6. 查看历史实验

从“实验记录”检索并直接打开已有结果，读取过程不重新计算或新增任务。历史记录保留原参数、来源与观测比较文件；复用参数会进入新的在线推演草稿。新建实验不再提供结果回放或实测对照模式。


## 7. 下一次实验

先保持背景、样本量和种子一致，换一个支持列表中的基因，再将两次运行加入候选进行描述性比较。调整“下一次实验”的草稿不会改变已经完成的运行结果。

进一步了解方法，阅读 [STATE 与 scCellFie 模型说明](MODELS.md)。

## 8. 服务状态

点击顶部连接状态进入独立“服务状态”页。进入页面时采集后端主机的数据库引擎与版本、连接延迟和连接池、NVIDIA GPU 型号、驱动、显存、利用率与温度，以及 CPU、内存、磁盘、操作系统、Python 与科学计算包版本。内存、磁盘和 GPU 使用以进度条展示；页面不定时刷新，点击“重新检查”重新采集。采集不到的硬件信息显示“未获取”。

分析服务分别显示配置是否启用、本进程的运行状态以及待完成任务数；无法检测的字段显示未获取，不推断为正常或零。GPU 信息来自 nvidia-smi；页面展示当前部署的主机，不代表其他远端计算机。
