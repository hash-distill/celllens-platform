## 1. 结论与适用范围

## 2. 数据来源与展示准入：最高优先级

| 数据/对象 | 允许的身份 | 应补齐的证明与限制 |
|---|---|---|
| 真实对照、扰动后 RNA | 实测表达 | 数据集 accession、版本/文件哈希、细胞系/克隆、处理条件、批次、原始条形码或源行号、尺度与预处理；不能仅以文件身份校验代替真实实验来源核实 |
| STATE 输出 | 模型预测表达 | 绑定权重、配置、有序基因面板、真实输入、运行编号、种子、预测群体与软件版本；预测细胞数不能称实验样本量 |
| 冻结真实结果 | 历史模型结果回放 | 明示原运行、原参数及原清单；回放不算新推理，不能用本次请求参数冒充生成参数 |
| scCellFie 任务/反应分数 | 实测表达派生评分，或模型预测派生评分 | 区分两条上游链；同一算法作用于预测 RNA 与实测 RNA 的一致性属于表达派生功能评分一致性，不是独立通量验证 |
| PCA/UMAP | 指定表达/任务空间的计算投影 | 记录所用矩阵、细胞集合、特征集合、缩放、拟合对象和种子；坐标距离/聚类形态不能当准确率、显著性或实测形态 |
| GPR/任务说明 | 知识库注释或方法示意 | 冻结数据库版本与来源；关联不等于因果、驱动归因、反应速率或实测状态 |
| 辅助大模型解读 | 对已有结果的解释文本 | 绑定上下文哈希、模型、提示版本；不得成为新增实验数据、验证分数或实测结论 |

需要完善的内容：

1. 在服务端统一执行正式展示准入，覆盖列表、按 ID 读取、比较、结果解读、助手和导出。正式入口不应因知道历史编号就能把合成记录混入正式结果；开发资产可以独立保留，不需要删除原始文件。本轮未发现正式构建会自动造数，历史合成数据仍可读取则是需要继续隔离的入口。
2. 统一来源枚举，明确实测、模型推理、真实回放、两种上游派生计算、知识注释和来源待核实；不要仅靠 `mode` 推断真实性。当前真实在线产物的 `result_kind` 可以为空，需要完整来源链共同解释。
4. 延续当前展示偏好：主结果只展示有有效数值的模型预测，不回填缺失值、不展示无数据关联。另在来源/完整性摘要交代筛选规则、完整输入数、可评分数与显示数，避免隐藏节点后误以为全部覆盖。
5. 零变化可以按当前规则从主视图隐藏；完整科学评价必须保留合法零值，不能直接用前端筛选后的 CSV 充当无偏测试集。显示导出应标明它是筛选结果。

### 需要补充的实测数据

- 从“个别扰动诊断”扩展为预先选定的多扰动面板，包含强/弱效应、代谢相关与非代谢相关扰动、不同背景及真实失败案例。先按可用测量、质量和批次规则选样，再看预测效果，避免挑好结果。
- 为每个候选保存每组细胞数、可比批次、独立重复、扰动效率/guide 信息、筛选前后数量和排除原因。技术批次不应直接当作独立生物学重复。
- 2026-10-12 的固定上游版本盘点发现 Jurkat/ABHD11 有 97 个测量细胞，而 RPE1/AQR 为 0。前者可作为后续对照抽取候选；97 不等于最终能进入评价的细胞数。后者应换有观测的示例，或引入其他真实数据源，不能生成“观测”补齐。该 0 仅适用于记录的固定 filtered revision，非所有研究。
- 实测数据尚需按输入可获得信息检查线粒体比例、低质量细胞、双细胞、批次/重复组成、guide/敲低效率及异常数据警示。缺少相关测量时如实写不可计算，不代造 QC。

### 全代谢覆盖路线仍处于实验阶段

仓库已有真实 SE/ST-SE 931 基因查询实验，不能说完全没有扩展工作。但它尚未替换活跃 ST-HVG：原始解码有负值、尺度条件未完全校准、源嵌入检查点身份未完全证明，部分背景诊断仍差于不变化基线；正式 scCellFie 评分尚未验收。

完善顺序应为：锁定匹配的编码/解码来源与训练目标 → 验证输出尺度、合法范围和重建误差 → 开发集校准 → 独立测试集检验变化 → 对照旧模型与简单基线 → 达标后独立版本发布。不能仅切换配置到 all、补零、手工剪裁或平移后宣称完整预测；有官方定义的后处理也需保留原值和规则。

## 4. 科学测试：先补协议，再补结果数量

当前主要缺口：

1. `configs/splits/replogle-v1.json` 仅列 12 个 test_groups，却声明 `frozen_test_group_count=969`；development/calibration 均为空。三个其他背景也没有开发/校准列表。来源拆分记录不等于项目正式评价协议。
2. `expression_validation.py` 明确输出 `protocol_status=unconfirmed`、`held_out_validation=false`。ALDOA 诊断协议也声明 `training_exclusion_verified=false`；目前没有证明测试扰动被检查点训练排除。正式留出协议应新增正确流程，不能只把 false 改成 true。
3. 四个背景使用各自 checkpoint，说明四个已接入背景可运行，不说明同一模型能泛化到从未训练过的细胞背景。
4. 现有细胞级 Wilcoxon 是诊断，不是独立生物学重复检验。预测生成更多细胞可能改变显著基因数量，不能靠增加 `n_cells` 证明更可靠。
5. 需要固定多种 seed、对照采样、各组细胞数及批次权重的敏感性检查；有独立重复时按重复/扰动聚合，并报告不确定性。没有独立重复时说明置信区间的重采样单位和限制，不把生成细胞间变化当生物学置信度。

建议先交付一套可冻结、可复跑的评价包：样本清单和哈希、训练/开发/校准/测试归属及依据、预处理、共同基因与批次规则、排除记录、基线训练范围、指标实现版本、重复策略、阈值制定依据和完整逐案例结果。训练排除无法核实的样本继续归为诊断，保留其价值但不冒称独立验证。

## 5. 指标：已有基础，缺比较体系与部分语义修正

已实现：表达差值 Pearson/Spearman、MAE/MSE、不变化基线、细胞级差异表达与 BH-FDR、DE overlap/AP；代谢任务差值 Spearman、MAE、方向一致率和 Top-K。常量相关性等部分不可计算结果已正确返回 null。

必须补齐或完善：

| 层面 | 缺口 | 建议验收内容 |
|---|---|---|
| 表达预测 | 除不变化外的比较基线不足 | 仅用允许的训练/开发数据拟合 context mean、perturbation mean、简单线性基线；同条件比较，不能读取测试观测调参 |
| 扰动特异性 | 多扰动 discrimination 和效应量排序仍为 null | 在冻结多扰动集合上评价，防止所有扰动输出近似平均响应仍获好均值误差 |
| 单细胞分布 | 均值好不代表异质性正确 | 增加分布差异、方差/分位数和检测率检查；依据真实重复噪声解释结果 |
| 效果汇总 | 少量挑选案例、缺分层统计 | 按背景/扰动类别报告分布、失败率、相对基线胜率；按扰动宏平均，另报细胞加权值，二者不混用 |
| DE 指标 | 字段命名与 Top-K 定义需要统一 | `effect_size_absolute_error` 当前实际是显著 DEG 数量绝对差，应改名；另定义效应幅度误差。明确 Overlap@K 在全基因或显著集合上排序、分母和不足 K 的处理；不把现有 AP 当未执行的完整官方 PR-AUC |
| 空指标 | 没有有效任务时返回 0 | 已复现：有效任务 0 时 MAE=0、方向一致率=0、Top-K=0；应为 null 并附不可计算原因和有效/排除数，避免零误差被当作完美结果 |
| 微小变化 | 任意非零或正负号容易被误读 | 数值非零仅代表模型变化；方向比较应预先定义可解释的近零区间，按开发集/测量噪声制定，不能看测试结果调门槛 |
| 功能评分 | RNA 派生任务一致性不是独立功能验证 | 分开报告上游 RNA 预测质量、覆盖质量、派生评分一致性。只有要声称真实功能/通量时，才补相应代谢物、酶活或同位素示踪等独立测量 |

官方评价工具也将扰动区分能力与表达误差分开，并强调比较基线。可参考 [Arc cell-eval](https://github.com/ArcInstitute/cell-eval) 和 [cell-eval2 指标定义](https://github.com/ArcInstitute/cell-eval2/blob/main/docs/metrics.md)。本地既有选定指标与 CellEval 0.8.2 的交叉核对不等于完整当前官方评测；未来应冻结选定版本与定义，不能跨版本拼接分数。
