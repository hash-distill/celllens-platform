# 前端对接

前端成品尚未交付。frontend/ 没有页面工程、package.json 或构建脚本，仅有部分共享 TypeScript 类型。本文是后续集成依据，契约见 [API](API.md) 和 [OpenAPI](openapi.json)。

## 首版工作台

支持“选细胞系与扰动 → 提交实验 → 查看状态 → 阅读结果和警告 → 下载报告”。首版围绕 K562 单基因分析。

| 区域 | 数据与行为 |
|---|---|
| 参数面板 | catalog 提供细胞系/扰动，参数受接口约束 |
| 运行状态 | run_id 查询真实阶段、进度与错误，终态停止轮询 |
| 细胞状态 | projection 按 control/predicted/observed 分组，显示实际方法 |
| 基因响应 | genes 表和 top_genes；正负变化、搜索/排序、截断提示 |
| 代谢功能 | metabolic-tasks 和 reactions；同时显示覆盖与 evidence_level |
| 预测验证 | 有匹配观测才显示 observed_delta；完整指标接口缺失，展示不可用原因 |
| 证据与警告 | 常驻运行编号、模式、参数、来源、可用覆盖和 warnings |
| 报告入口 | completed 后请求 report，产物缺失时显示不可用 |

模型 ID 可从 catalog 读取，但运行级模型/数据哈希和 manifest 没有查询接口。不能把当前 catalog 当作旧运行完整溯源，也不能编造哈希。真实任务摘要 determinant_genes 为空，完整基因—反应—任务解释链仍缺后端数据。

## 调用与处理顺序

1. 查 health、ready 与 catalog；ready 返回 503 不一定影响预计算，结合模式和数据库状态判断。
2. 查选定细胞系的扰动，校验参数后 POST /runs，避免重复点击。
3. 保存 run_id；已 completed 直接读结果，否则轮询运行状态，终态或离开页面时清理轮询。
4. 各视图独立读取，局部 404 不应导致整个页面不可用。
5. 缺失值保留 null，不替换成零；显式转换 CSV 数字字符串，不在浏览器重算科学指标。

编号来自创建响应或用户指定的已有运行，不硬编码历史编号。当前无运行列表、取消接口或账户系统；浏览器可本地保存近期编号，并说明其本地性质。

## 服务连接

使用统一请求层和可配置基址。当前后端没有 CORS，开发时通过前端服务器把 /api 代理到后端，发布时同源反向代理转发该路径。具体配置待取得前端成品后按其技术栈设置。

局域网里的 127.0.0.1 指向前端同学自己的电脑；联调使用后端实际局域网地址。启动见 [运行文档](OPERATIONS.md)。

无 GPU 开发使用 K562/MYC precomputed 样例，常驻标注“合成演示数据”。catalog 不能列举预计算包，先使用这一已提供样例。缺投影/反应/报告时展示“本次结果未提供”，不随机补齐。

## 集成验收

| 场景 | 应有结果 |
|---|---|
| 真实 K562 在线请求 | 创建、轮询、来源、结果及报告正常，缓存可直接完成 |
| 无 GPU 预计算 | 流程可用，合成标识常驻，缺失视图说明明确 |
| RPE1 或未就绪模式 | 显示不可用原因，不误报成功 |
| failed/503/422/404/409 | 错误可读，无白屏、无限加载或伪造结果 |
| 代谢降级 | 基因结果可查看，代谢区域显示警告 |
| 验证页 | online 不显示真实观测结论，缺指标不填数值 |
| 切换任务/离开页面 | 旧请求及轮询不覆盖新任务 |
| 报告与表格 | 数字与接口一致，保留 null、截断和来源说明 |
| 浏览器 | Chrome/Edge 主要桌面尺寸可用，真实 API 与 fixture 记录分开 |

交付需包含源码、依赖锁文件、配置示例、启动/构建命令、实现清单和联调记录。交接问题附参数、运行编号、接口、响应及复现步骤。
