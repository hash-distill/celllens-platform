# 前端工作台

前端源码统一位于 frontend/，采用 Vue 3、TypeScript、Pinia、Vue Router、ECharts 和 Three.js。启动与构建见 [部署与启动](DEPLOYMENT.md)，检查与排错见 [运行文档](OPERATIONS.md)，接口语义见 [API](API.md)。

## 三维科研工作台（2026-10-04）

界面采用浅色停靠面板和深色三维视窗。左侧设置实验、管理场景对象，右侧检查选中细胞器；下方读取本次结果摘要。桌面端面板独立滚动，窄屏按结构视窗、实验设置、对象属性排列。原项目 logo 保留。

`/workbench` 默认打开结构示意；`/runs/:runId?tab=structure` 在同一布局中读取运行。原 `tab=cell|genes|metabolism|validation` 链接继续有效，表达空间保留后端二维随机投影。基因条形和表格选择联动，数值检查器展示实际平均表达；缺少观测时标“未提供”。

`src/scene/cellModel.ts` 以确定性几何构建膜、核与核仁、内质网、线粒体嵴和高尔基体；`CellViewport.vue` 使用真实 WebGL 渲染、OrbitControls、射线拾取、膜剖切和标签。支持图层显隐、不透明度、自动旋转、复位、全屏和当前渲染 PNG 导出。场景状态独立于科学结果；没有细胞器到代谢任务的可靠映射时，检查器明确显示“待映射”。

隐藏页面和离开视窗时停止连续渲染，减少动态偏好关闭自动旋转及镜头过渡。卸载释放 GPU 资源；WebGL 不可用时显示可选择对象的二维 SVG 示意。结构并非设计 PNG 贴图，也不表示实测显微影像或模型预测形态。效果图中的写实细节不等于当前程序化模型的精度。

`/demo?run=<run_id>&step=0` 展示细胞结构、基因扰动、代谢响应、验证与证据四章；`step` 范围 0–3，刷新保留章节与运行。自动播放每章 22 秒，可暂停、回退；页面隐藏后停止自动推进。方向键切章、空格播放/暂停（输入框及原生按钮操作除外）、Esc 返回该运行。未指定运行时只展示结构和结果空态，不创建任务、不替换 Mock 数据。结果页的“演示本次实验”自动绑定该运行。

三维代码和演示路由懒加载。三维 chunk 含 Three.js，当前约 590 kB（gzip 约 151 kB），构建会报告大 chunk 提示；不为压低警告阈值改变渲染功能。当前不增加三维表达坐标、分布图、形态预测或区室因果关系。

验证：在后端与 Vite 启动后执行 `python scripts/check_frontend.py`（原 9 项回归）和 `python scripts/check_3d_frontend.py`（真实 API/WebGL 检查，自动寻找本机已完成在线运行，也可传 `--run-id`）。浏览器脚本需安装 Playwright。新截图和检查结果写入 `reports/frontend/`；精选 [页面截图](screenshots/README.md) 和 [历史检查记录](verification/2026-10-04/README.md) 单独维护。生产入口可使用 `python scripts/check_production_frontend.py --url http://127.0.0.1:8000 --smoke` 检查，生产直达和刷新 `/demo` 由后端 SPA 路由支持。

## 页面与数据流

项目图标统一保存在 `frontend/public/favicon.png`，使用交付的透明 PNG 原图。网页页头、浏览器标签页、Apple 触屏书签图标和 README 共用该文件。Vite 开发服务直接提供 public 文件，生产构建会复制到 dist；后端提供 `/favicon.png` 并兼容 `/favicon.ico`，均以 PNG 内容返回，更新时要求浏览器重新验证缓存。

工作台提交参数；运行详情展示阶段、投影、基因、代谢、匹配观测和证据；候选比较最多并列四个本机保存的运行；使用说明解释来源与服务状态。

src/api/ 统一请求和数值转换，src/stores/ 管理运行及分块结果，src/components/tabs/ 展示各结果，src/charts/ 只绘制接口数据。页面路由懒加载，ECharts 按需注册。基因、任务和反应表每页 50 条；搜索/排序后回到第一页。基因 CSV 导出全部已加载接口行，包含来源和截断说明，不限于当前分页。

请求默认 30 秒超时，覆盖响应头和正文；创建不自动重发。轮询串行执行，网络中断与超时退避重试，终态或离开详情后停止；局部结果失败只影响对应区域。

## 来源与本机记录

真实 API 是默认模式。前端 Mock 必须由 VITE_ENABLE_MOCK 或使用说明中的本机开关显式开启，失败不会自动切换。详情、证据栏、候选比较及导出文件标明来源。

Mock 运行持久保存在本浏览器的独立存储中，编号不会因刷新复用；最近运行和候选按 Mock/API 分开保存。浏览器禁止存储时降级为会话内记录。后端 precomputed 与前端 Mock 不同：前者创建数据库运行并读取经哈希核验的演示包，当前包仍为合成数据。

扰动选项按 cell_line 和 mode 读取，预计算只显示通过校验的组合，切换模式后无效的旧选择会阻止提交。开发代理目标由 frontend/.env.local 的 CELLLENS_API_PROXY_TARGET 控制；浏览器保留 VITE_API_BASE=/api。生产页面由后端同源提供。

## 科学解释边界

证据栏读取本次历史 manifest 的模型、数据和哈希，不用当前 catalog 代替历史版本。代谢页请求完整有效任务，旧产物缺失时标明退回 Top 摘要；无有效预测变化的任务排除并提示，不能补零。

验证页只读取后端已有指标，不重算或填样例数值。开发验证名单和实验拆分尚未确认，提交入口保持关闭；即使已有匹配观测指标，也显示协议待确认。真实任务 determinant_genes 仍为空，基因—反应—任务关系图需要可靠映射后再实现。候选比较未自动核验版本，不输出实验优先级评分。
