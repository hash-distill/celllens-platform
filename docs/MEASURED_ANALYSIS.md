# 实测优先的公开数据分析

2026-10-22。CellLens 先回答“这个背景和扰动有没有现成实测”，再决定直接分析或进行模型预测。当前分析固定公开源，不提供任意文件上传。

## 使用流程

1. 打开 `/data-catalog`，按背景、目标、有无实测或模型支持范围查询。
2. 显示“本源有实测”时，点击“直接分析实测”，进入 `/measured`。本地未下载仍算源有实测，提交后按需提取对应细胞。
3. 设置目标实测细胞上限和种子，点击开始。上限 1–4,096，默认 256；实际数量不会超过真实可用细胞数，不复制细胞补齐。
4. 查看匹配前后人数、共同基因数、表达均值差、PCA/UMAP 和可用的 scCellFie 评分。分析详情使用 `/measured/{id}`，刷新和重启后仍能查询历史。
5. 下载完整基因／任务／反应 CSV、投影 JSON、HTML 报告或分析 ZIP。表格分页和搜索不裁剪下载的完整结果。

已有实测也可明确选择“预测并评估”，在模型工作台运行 STATE 后使用原有实测比较功能。本源没有实测且模型词表支持时只能做探索预测；词表外或未知背景当前不支持。详见[泛化证据](GENERALIZATION.md)。

## 输入与计算

固定源为 `arcinstitute/State-Replogle-Filtered` revision `d790193bb2c93726541a75ca3fa873a92ed44da5` 的 `replogle_concat.h5ad`。覆盖索引统计完整的 643,413 个细胞元数据，不通过是否已下载推测有无实测。

优先使用哈希有效、背景与目标标签正确的已登记真实对照和扰动观测。缺少或人数不足时，按固定 revision 范围提取所需表达行；缺对照时最多提取 1,024 个 non-targeting 对照。不会下载完整约 30 GB atlas，不下载 STATE 权重。旧登记对照不含可验证 revision 时如实记录该限制，不补造来源证明。

使用输入的完整共同基因集合，不为了匹配模型再截取 2,000 HVG；**可用范围仍受本地输入文件的原有基因面板限制**，实际基因数以本次摘要为准。源表达按照已登记的 `log1p(CP10K)` 处理。差值为目标扰动实测均值减真实对照均值，单位为 `mean(log1p(CP10K))`，不称作 log2 fold change 或显著性。

有 `gem_group` 时只保留两个群体共同存在的批次，保留实际细胞频率，不重新加权或一一配对。没有共同批次时停止分析；缺少批次标签时保留未匹配的描述性分析并明确提示。界面和导出分别记录输入与实际分析人数。细胞记录数不能替代独立生物学重复数。

PCA 以实际对照拟合参考轴，UMAP 在两个真实群体上共同拟合。图中只存在 `control` 与 `observed`，没有模型预测群体。坐标反映表达特征，不是形态、物理位置或单细胞前后轨迹。scCellFie 使用真实表达恢复的线性 CP10K 和冻结人类知识库，其分数为表达派生支持程度，不是实测通量。缺少可选依赖或数据库时明确显示不可用原因，仍可保留有效表达分析。

## 运行与来源保存

实测分析使用独立 CPU 子进程，不受 `CELLLENS_WORKER_ENABLED`、`CELLLENS_GPU_AVAILABLE` 或 checkpoint 是否存在限制。需安装 `analysis` 科学依赖、连接 MySQL 并执行最新 Alembic 迁移。`report` 提供原有完整科研绘图／PDF 能力，可按部署需要同时安装。无 GPU 环境把两个预测开关设为 `false`；原有预测功能仍需其完整依赖、权重及 GPU。

新表 `measured_analyses` 保存状态；结果位于 `data/derived/measured/{id}/`。原 `runs`、模型、输入和旧比较不被改写。同一项目一次执行一个实测分析；可取消，失败或中断后以新编号重试。已完成结果通过原子目录发布，读取时核对清单、结果及引用输入哈希，变化后返回 409，不能悄悄用新文件替代旧来源。

ZIP 含结果、分析参数、实际来源引用及 SHA-256、依赖版本、批次选择、单位和限制说明。新提取的输入位于包内 `inputs/`；复用的原始文件以项目相对路径和哈希引用，**不会自动复制进 ZIP**。跨机器完整复现还需保存这些引用文件及冻结代谢库。迁移或备份需要同时保存数据库和相应文件。

## 当前范围

实测分析用于公开观测的描述性探索；它本身不证明预测模型泛化，也不完成生物学因果验证。AI 侧栏现有解读接口绑定预测运行；本页提供真实统计、图表与报告，暂未接入实测来源的 AI 解读接口。预测评估和旧预测导出保持独立。
