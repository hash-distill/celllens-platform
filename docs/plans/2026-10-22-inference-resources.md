## 设计

服务页按 K562、RPE1、Jurkat、HepG2 展示资源卡片；用户点击后由运行后端的机器下载固定官方版本中该背景的 6 个模型文件，不会下载其他背景。已有校验通过文件跳过，断点文件可续传；下载进度、校验阶段、取消、错误与重试由只读轮询显示。下载到部署机项目目录，远程访问时不是浏览器下载目录。

对照 H5AD 是从固定官方 atlas 提取的本地产物，并没有同名官方下载文件。缺失时按当前背景、固定随机种子和最多 1024 个真实非靶向细胞进行范围读取、验证并冻结为新版本；不整包下载 atlas。不覆盖现有合法对照，不修改旧记录的资产身份。新对照使用新 dataset ID，原登记保留供历史结果核验；只为本次在线推理登记，不冒充独立验证数据。

共享基因面板、模型适配配置和 scCellFie 库来自源码，重复利用。资源准备不安装 Python/CUDA，不表示 GPU、依赖、worker 就绪。完成后刷新目录，无需重启。原始模型受 Arc 非商业许可约束，首次发起时明确勾选知悉来源与许可。

API 仅接收背景枚举，不接收 URL 或文件路径；固定来源/哈希/大小、范围响应校验、分块写入、发布前校验、防路径越界、同源请求保护和进程间下载锁。任务状态落盘，进程中断后标记可恢复；临时文件不作为已就绪资产。控制提取子进程可取消，下载单任务执行，避免资源争用。

README 采用简介与预览、特性、技术栈、快速开始、页面准备资源、开发与配置、目录结构、常见问题、验证与许可的顺序。快速开始先完成数据库和依赖，再启动无权重页面，最后选背景准备；本机 MySQL 与 Docker 数据库二选一。保留上层目录 README 的导航职责。
