# 大模型接入配置改进

用户授权：通用 API 接入配置，模型检测、配置导入、推理强度和上下文。

采用成熟客户端的提供商—连接—模型流程：浏览器保存多组命名连接，密钥只进当前标签页会话；模型列表请求与文本生成测试分开，失败可手填。支持本系统版本化 JSON、通用平铺 JSON 和常用 `.env` 键，文件或粘贴导入先预览，导出不含密钥。导入不触发网络请求。

按服务协议映射可选推理参数，默认省略，兼容性由具体模型决定。Claude 支持预算和自适应模式；不从模型名字猜能力。上下文窗口是用户声明的单次输入加输出预算，以 UTF-8 字节数估算检查并明确标注误差；不足则拒绝发送，不截断科研证据。仍只发送本次预览摘要，不增加历史对话或发送原始矩阵。

验证：先写模型发现、参数映射、上下文预算、导入/导出与会话密钥隔离测试；运行现有解读回归、后端检查、前端类型检查及构建；受控浏览器核验导入、模型选择、保存切换与主题/窄屏。模拟上游检查不等于真实厂商连通性。
