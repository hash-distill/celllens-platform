# 页面与导航重组

日期：2026-10-08。依据用户提出的四项具体修正，承接已授权的响应工作台改造。

1. 首页 `/` 独立介绍产品、方法流程和主要研究入口；不带实验设置侧栏。
2. 工作台 `/workbench` 集中配置、提交、进度与结果，顶部横向配置；结果身份由 URL 的 run 参数固定，编辑草稿不改变已有结果。
3. 删除细胞器结构视窗、几何生成、场景状态与专用导航/侧栏。任务—反应—基因功能网络作为运行级知识关联保留。
4. 实验记录 `/records` 从服务器数据库分页查询；按创建时间倒序，支持目标/背景/编号检索、状态与来源筛选、打开分析和加入比较。浏览器比较候选独立保存。
5. 顶部统一六个主入口；主页面共享宽度和移动端边距。旧结果链接重定向至工作台，旧结构页签回到响应概览。
6. 验证真实服务器历史、分页刷新/返回、实际预计算提交、局部故障重试、旧链接及三种屏幕尺寸；保留单细胞状态与追溯回归。同步文档和 OpenAPI。

结果与验证见 [页面验收](../../verification/2026-10-08-navigation.md)。
