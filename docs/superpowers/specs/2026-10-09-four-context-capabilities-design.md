# 四背景预测、演示与实测诊断

用户已确认范围：四个背景均能展示预测、演示和实测诊断。采用现有真实模型与测量资产补齐能力。

## 方案比较与决定

1. 推荐：四个活跃 ST-HVG 模型各运行 ALDOA 实测诊断；其冻结真实结果作为离线演示。优势是展示真实差异，可溯源；需要为回放结果保留真实来源标记。
2. 四背景生成合成演示：工程容易，但不能体现各背景真实模型差异。现有 K562/MYC 合成包继续保留，不扩充相同模拟数值来冒充四背景差异。
3. 立即启用实验 SE/训练输出头：科学输入与监督范围仍未解决，不在本次范围。

## 数据和契约

四背景共同扰动 ALDOA 已有冻结实测 H5AD，分别 33/29/34/33 个细胞。拷贝原文件到登记的数据目录，表达与源细胞身份保持不变；原对照、旧观测文件及全部旧运行保持原哈希。登记诊断协议及 SHA-256，协议记录背景、扰动、测量文件哈希、来源 revision、批次策略与训练排除未核实。新建 validation 只接受该协议中的扰动，名单为空或协议/测量哈希失配则不开放。

诊断使用现有 expression-cp10k-v2 链，三个来源取共有 gem_group，无观测填补或复制。保持 held_out_validation=false；不得称为独立留出验证。现有四个模型、2000 基因面板及冻结 scCellFie 数据库不变。

## 演示

预计算包增加 frozen_model_result 类型，必须保存原真实运行 manifest 并逐项核对所复制结果哈希；生成新回放运行时重绑定 run_id，重新登记产物，记录原运行与清单哈希。预计算不运行 STATE 或 scCellFie。原合成包仍为 synthetic_demo 类型，旧包默认归入合成；不得仅靠请求模式判断真实/合成。

RunRecord/RunSummary 返回 result_kind；来源标签、观测说明、投影、记录、比较、演示均读取该字段。回放仅请求已有结果，不把请求 n_cells/seed 声称为新采样。用户可在三种模式间切换，匹配验证显示为实测诊断并解释边界。

## 错误与验收

协议缺失、篡改、未登记扰动在创建任务前失败；伪造 frozen 类型、源清单错误、上下文不匹配在预计算加载前失败。回放的追溯/完整性须匹配新运行及原表达文件。

验收：四背景真实新诊断完成，预测槽确有模型输出；全部旧运行与对照文件哈希不变；四背景三模式目录正确，四个真实回放完成且数值不变，合成旧包保持标记；全后端测试、静态检查、前端构建和桌面/手机真实页面核验。
