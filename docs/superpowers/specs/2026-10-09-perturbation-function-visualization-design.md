# 扰动前后细胞功能可视化：系统对照与拟议设计

日期：2026-10-09。输入为主目录《相近系统调研.md》及当前 CellLens 源码、真实运行产物。本文记录可行性核验与设计。用户随后要求实施，一期功能现已完成，见 [验收记录](../../verification/2026-10-09-function-visualization.md)。本次界面工作不生成新的生物学预测结果。

## 目标与范围

将“细胞工作”解释为当前能够预测和解释的基因表达、关联反应和代谢任务。让科研人员回答：哪些功能的表达支持发生变化、涉及哪些关联反应/基因、观测是否支持、哪些证据缺失。

一期推荐实现功能前后对比与知识关联网络；单细胞视图作为辅助钻取。形态、区室定位、代谢物浓度和随时间变化不属于当前输出，不能由表达或任务分数自行生成。

## 相近系统中已核验的借鉴点

| 系统 | 公开资料核验 | CellLens 可借鉴 | 差异与依赖 |
|---|---|---|---|
| ROSALIND | 支持基因表达、热图、差异分析及通路图联动；通路图叠加表达颜色 | 从变化列表进入功能图；点节点查看前后数值和关联基因 | 通路富集需独立背景基因集、数据库、统计契约，不能将现有任务分数改名为富集结果 |
| NAViFluX | 原论文描述代谢网络、通路/子系统图、模型细化及通量模块 | 稳定布局、通路/任务选择、交互式反应网络 | 其通量能力依赖代谢模型和计算；CellLens 当前是反应/任务活性分数，尚无同等 flux 输出 |
| Biohub Virtual Cells Platform | AI Workspace 提供单细胞分析、嵌入和数据探索 | 在同一运行内按来源、基因表达和真实元数据查看细胞 | 当前随机投影需要另外建立可解释的共同投影协议；不能将自绘坐标称为模型 SE 或组织空间 |
| BioTuring | 官方平台页将 BBrowserX 定位为单细胞分析、SpatialX 为含组织空间位置的分析 | 单细胞与功能信息联动的产品思路 | 组织位置需要实际空间数据；当前没有此类坐标 |
| scCellFie | 官方仓库说明从单细胞/空间转录组推断代谢任务活性 | 保留原分数、GPR 关联、官方完整性和来源 | 分数单位独立于表达，不能转换为 ATP 产量、代谢物浓度或湿实验通量 |

## 现有资产核验

现有 `TaskTrace.vue`、`TraceNetwork.vue` 已能展示选定任务的基因—反应关联、列表和三维布局。`task_trace.json` 保存任务/反应/基因的 control、predicted、predicted_delta、observed_delta、GPR 规则和知识库来源；关联类型明确为 `knowledge_association`，没有经过验证的因果贡献归因。

一期可以复用这些数值和产物接口，不更改 STATE 或 scCellFie 计算，不重新训练。现有三维图只是知识关联的空间布局，不能当作细胞内真实位置。

## 三种设计路线

| 路线 | 展示 | 当前可行性 | 决定 |
|---|---|---|---|
| 功能前后对比 + 基因—反应—任务网络 | 看变化、点功能追溯数据 | 已有真实产物，主要是前端和完整列表接口组织 | 推荐一期 |
| 底物—反应—产物通路图 | 类似代谢地图，叠加分数 | 缺反应方程、代谢物和区室，需要新资产契约 | 二期 |
| 细胞/细胞器形态及连续动画 | 外形、位置、运动或随时间变化 | 缺图像/空间/时间数据及对应预测输出 | 当前只能提供明确标注的独立示意，不作为预测视图 |

## 一期具体页面

入口为完成运行后的“功能前后对比”，四背景和真实回放共用当前 run_id。沿用现有工作台颜色、字体和来源标签；随机投影移到“单细胞表达分布”辅助位置。

布局：左侧功能任务列表；中间前后并排的同一网络；右侧当前节点的数值、单位、缺失与观测证据。顶部提供“对照”“模型预测”“预测−对照”；已有真实观测的运行增加“实测观测”，无观测保持明确缺失。

中间图：

- 使用同一批节点、边、布局和缩放，对照/预测两栏严格共用位置。点击任务只展开该任务的关联子网，避免把全部数据库节点堆到一张图。
- 节点分为任务、反应、基因三种；边标为任务关联与 GPR 关联，不画成已证明的作用传播。
- 差值采用双向色带；零变化中性色，缺失值灰色并带“未预测/未评分”。灰色节点不算零变化。
- 基因、反应、任务单位不同，三类分别设置色标；同类的前后图共用范围，不把三种数值相加或比较绝对强弱。
- 关联列表显示完整数量及当前显示数量，分页/折叠用于可读性；截断节点明确提示，可在完整列表核对。
- 以具体任务为基本功能单位。数据库的 System/Subsystem 用作导航分类，不把其中任务分数简单求和成为“整个细胞工作效率”。

右侧信息：名称/任务分类、对照值、预测值、差值、可选观测值、GPR and/or 规则、完整性、缺失基因、源运行和清单。标题使用“关联基因”，不使用未经验证的“关键驱动基因”或“因果贡献”。

交互阅读顺序：

```mermaid
flowchart LR
    A[选择一次真实运行] --> B[查看功能任务变化]
    B --> C[展开关联反应与基因]
    C --> D[核对前后数值及缺失]
    D --> E[查看实测诊断与来源]
```

图中的箭头是操作顺序。生物网络连线表示冻结知识库关联，不是本次扰动的因果验证。

## 用真实数据说明展示效果

HepG2/ACD 当前保存的“ATP generation from glucose (hypoxic conditions) - glycolysis”任务：对照分数 6.9518、预测 6.7086、差值 −0.2433。页面可显示该任务分数下降，点击后展开关联反应及可用基因表达。

允许的说明是“该任务的表达支持评分下降”。不能据此写“ATP 产量下降”“细胞能量降低百分之多少”或“ACD 通过某反应造成该变化”。该运行没有扰动后的实测观测，且输入覆盖有限，需要同时显示覆盖与未验证状态。

一期仅有两个/三个状态快照。按钮切换与选中高亮可以帮助阅读，不生成所谓中间时间点，也不按分数驱动粒子流速来表示真实代谢流动。

## 数据与实现契约

复用 `/runs/{run_id}/metabolic-tasks?scope=all`、`/genes`、`/task-trace`、`/completeness`、`/validation`、`/provenance`。页面不解析 H5AD、不重算指标、不用当前数据库替换历史关联。

节点只能使用当前产物中的值；观测均值仅在对照值与 observed_delta 均存在且单位一致时还原，并注明来源。旧运行没有追溯/完整性时保留现有数值列表，显示缺失，不拼入最新网络。合成演示保持合成标识，真实回放保留原始运行链接和“本次未重新计算”。

拟新增独立功能对比组件及二维可交互网络，复用现有选择状态和追溯组件。现有三维网络可保留为可选视角；二维功能图负责清晰比较前后数值。

需要补齐的展示接口限于完整分页/节点数量与当前保存的关联数据，不扩充未经预测的基因。细胞器映射、Reactome/KEGG/代谢模型、富集统计和新 PCA/UMAP 协议分别作为独立后续工作，不混入一期结果。

## 验收条件

1. 四背景真实运行/真实回放显示各自保存值，不发生跨 run_id 混用。
2. 前后节点与坐标一致；基因、反应、任务各自色标一致，单位可见。
3. 零值、缺失、未预测、非有限值区分；缺少观察时不产生观测节点或指标。
4. 示例 −0.2433 来自原文件；旧结果哈希及科学矩阵保持不变。
5. 功能点击联动关联图、前后数值、完整列表、覆盖和来源；截断节点可追查。
6. 浏览器检查桌面/手机、来源类型、缺失产物、同布局切换与导出说明。二维图键盘/列表操作可替代拖拽操作。
7. 页面不声明真实代谢通量、细胞内位置、形态变化、因果贡献或连续时间预测。

本方案是基于现有资产的实现设计。已核验外部资料和本地数据，未将任何产品宣传或图片当作 CellLens 已具备的能力。
