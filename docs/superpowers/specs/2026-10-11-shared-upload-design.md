# 无需账号的上传分析设计

用户明确取消登录与注册，改为现有受控科研环境中的共享工作区。进入上传页面即可使用；不自动创建匿名账号、不要求密码或恢复密钥。能访问工作区的人可读写新增共享数据，页面明确标注共享范围。

数据集是一份不可变 H5AD 上传版本，保存声明、校验、文件哈希与来源。一个版本可对应多次分析，各自记录名称、分组、参考组、种子、状态及结果。数据集按名称搜索，任务按数据集和状态筛选，详情可通过稳定地址复查。归档禁止新任务，保留原文件和历史结果。

沿用完整面板质控、PCA、描述性表达比较与 scCellFie CPU 链路；不扩大到用户 STATE 预测。移除账号 API、会话、登录界面、前端登录守卫及建账号脚本；保留旧数据库表和归属记录，新增 owner_id=NULL 作为共享域，仅该域通过接口和队列访问。旧私有文件不自动公开，需要维护者明确可共享后重新上传。

工作区使用全局源文件配额和三个待完成任务上限，跨进程上传/提交锁防止并发绕过；写请求检查浏览器来源，请求体在解析前设限，原有 HDF5 预检和哈希核验继续保留。安全范围是受控部署，不提供身份隔离。

验收覆盖匿名上传、两浏览器共享、跨站拒绝、筛选与任务命名、全局队列上限、旧私有记录不可公开、归档/下载/哈希校验、真实表达代谢链路，以及 SQLite/MySQL 保留式迁移。原 README 本地修改单独保留。
