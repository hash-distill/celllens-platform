# 用户数据与下游分析设计

本设计落实已获用户同意的上传、数据管理、分析接口和前端页面方案。

## 工作流

管理员通过本机命令创建首个账号，登录后可创建普通科研用户。用户登录后上传人类表达 H5AD，声明表达尺度、矩阵来源和原始计数是否包含完整文库；系统校验后保存不可变数据集版本与 SHA-256。用户可浏览、下载和归档自己的数据集，归档不删除既有分析依据。

首批任务是表达探索（逐细胞质控、真实表达 PCA、逐基因均值与检出率）和 scCellFie 代谢分析。可选择 obs 中的分组列及参考组，导出描述性的表达/代谢组间差值，不将其称为显著性或因果效应。代谢分析使用完整上传基因面板与冻结人类数据库、官方完整性报告，不裁成 STATE 的 2000 个基因。

三种架构中，直接覆盖注册资产会影响既有结果；只增加上传按钮不能完成分析和权限隔离；采用独立用户数据域，复用冻结数据库、表达尺度和 HGNC 解析服务，保留预设运行入口。

## 约束

- 首期只接收 H5AD 的 X 或 layers，拒绝不明确的表达尺度、无穷/负值、重复细胞/基因、损坏文件、外部 HDF5 链接和超过资源上限的文件。
- raw_counts 全文库输入可显式计算总计数；子面板必须给出真实全文库 total_counts 列。CP10K/log1p CP10K 不再按代谢子面板归一化。
- 用户文件与结果均以随机 ID 保存于非公开目录。新数据集及其任务、结果、下载必须登录并检查所有者；管理员账号不默认取得其他用户文件内容。
- 账号使用加盐密码哈希，随机 HttpOnly 会话 Cookie，服务端会话有效期、退出撤销、登录失败锁定；写操作校验 CSRF 令牌。账号由管理员创建，不开放自行注册。
- CPU 分析队列持久记录任务并以数据库锁防止重复领取，重启恢复未完成任务；无需 GPU。任务失败保留可读原因，不伪造完成结果。
- STATE 兼容性只报告注册背景、基因面板与元数据条件。用户数据直接驱动 STATE 不在首期范围，任意背景不能据此声称受模型支持。
- 现有预设实验及历史记录是共享科研入口；本期用户数据权限不等于已对整站历史数据完成多租户改造。

## 验收

验证账号登录/退出、CSRF、用户交叉访问拒绝、大小与文件内容校验、数据归档与溯源、任务恢复、数值归一化与组间差值；运行真实 scCellFie 完整冻结数据库链路。前端验证登录、上传、选择分组、创建任务、查看 PCA/表格、下载与归档，并执行既有后端回归、类型检查和构建。
