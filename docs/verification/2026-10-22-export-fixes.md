## 修订内容

1. **关联完整性**：任务 JSON 保留 API 原始完整 trace、GPR 和原计数，筛选状态另存 display。切换任务取消请求并丢弃晚到响应。覆盖目录 JSON 保留全部源反应条目、纳入规则和明确的完整/部分/导出计数，缺项单独列出。
2. **CSV 契约**：基因、任务、反应导出使用服务端完整表，保留零变化；追加单位、聚合、实际人数、群体/selection_id、来源模式、模型与数据库版本。原分析和共同批次诊断分别导出；缺少实测为空。历史无逐细胞表时，优先采用冻结 validation_population.selected_cells，未核验计数保持未知。
3. **PDF**：附中文任务名/稳定 ID、覆盖比例与去重基因数、覆盖证据含义、原分析/诊断群体、训练排除/留出限制与不变化基线说明；无比较时明确不可验证。优先嵌入可许可中文 TTF；缺失字体时可见提示。覆盖分数显式换行，数值按可用宽度适配字号，避免数字拆行。历史 task/source/score 汇总行不算作细胞数。
4. **交换包**：新增 analysis、single-cell、network、ranking 四类 ZIP 和所选任务网络包；白名单导出科学文件，manifest 记录来源/载荷哈希及缺件；不包含命令日志或凭证。analysis 内含修订 PDF。
5. **规范 H5AD**：按冻结契约从 STATE 的正确表达槽位与目标扰动群体构建标准 X/obs/var/obsm/uns；X 为 log1p(CP10K)，不伪造 counts/raw。仅附既有二维坐标；H5AD 只放原分析群体，诊断实测另存 comparison。
6. **下载可靠性**：特征名加入安全 slug+SHA-256，SVG/PDF/PNG/JSON 不再因选择不同基因而重名。统一 MIME、扩展名、内容签名、错误和取消处理；局域网普通 HTTP 下提供一致 SHA-256 回退。CSV 文本防公式解释，不改变数值负号。
7. **来源校验**：实测 comparison.json 必须登记输出哈希；反应 CSV 在实际读取前后强制核对登记哈希；缺失条目拒绝，不接受未绑定内容。
