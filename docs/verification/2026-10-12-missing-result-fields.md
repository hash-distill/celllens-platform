# 列表空值与关联基因修复

日期：2026-10-12。核验对象为当前 8000 服务中的 RPE1/AQR 与 Jurkat/ABHD11 两个已完成在线实验。

## 原因

基因接口返回的对照、预测及预测差值全部存在；两个实验未提供扰动后实测，观测相关字段缺失。前端却始终显示观测列与详情中的观测表达，造成大量“未提供”。

代谢任务接口的 `determinant_genes` 是评分驱动归因字段，当前未做经验证的归因，故为空。代谢表把它标为“关联基因”，造成“关联基因尚未提供”。实际冻结 `task_trace.json` 已保存任务—反应—基因关联。

追溯详情中的部分空值是真实输入限制。例如甘油糖异生关联的 ALDOA、ALDOB、ALDOC 不在这两个实验的预测基因面板内，没有保存表达值；TPI1 在面板内且有表达值。知识库关联名称不代表本次有数值；任务总分存在也不代表所有关联反应均能评分。

## 修改

- 基因表、基因详情及代谢表依据保存数据判断是否存在观测。无实测时隐藏对应列，统一解释原因；只要存在观测值，继续保留观测列及个别空值。
- 代谢列表通过现有 `scope=all` 追溯接口读取本实验冻结关联，从全部反应的关联基因去重生成名称列表，支持展开；不填充或混用 `determinant_genes`。
- 仅加载当前分页，最多四个并发只读请求；换页、切换实验或组件销毁会取消旧请求。缺少关联、加载中及读取失败分别提示，失败可重试，不伪造名称。
- 追溯中无有效表达/反应分数时注明具体数据类型；知识库关联与有效评分仍保持区别。

## 验证

`npm run build`（含 Vue TypeScript 类型检查）通过。`python -m scripts.check_missing_result_fields_frontend --url http://127.0.0.1:8000` 通过：

- 两个实际实验的基因表显示值与保存接口相符，无空观测列。
- 每个实验第一页的全部关联基因名单与完整冻结追溯相符；换页加载正常。
- ALDOA 等缺失表达和 FBA 缺失反应分数保留并说明原因。
- 仅浏览器内注入的验证数据确认：已有观测值不会隐藏；损坏追溯明确报错，不用驱动归因或其他来源替代。
- 浏览器无异常；两个实验所有冻结产物 SHA256 与实验记录前后相同。
