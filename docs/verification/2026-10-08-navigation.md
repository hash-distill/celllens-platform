# 页面与导航验收

日期：2026-10-08。本记录承接[响应工作台验收](2026-10-08-response-workbench.md)，覆盖用户提出的首页、结构删除、工作台命名/导航和历史实验管理修正。

## 已实现

- `/` 为独立首页，介绍模型链路、研究主线和工作台/记录/比较/演示入口；无参数侧栏或虚构结果。
- `/workbench` 为统一实验工作台：上方横向参数，下方进度和结果；已有结果时默认折叠下一次实验草稿，可复用参数。单细胞状态、基因、代谢、验证为同一工作台内的页签。
- 顶部提供首页、实验工作台、实验记录、实验比较、演示模式、使用说明；六页采用同样的最大宽度和边距。
- 已删除细胞器几何生成、结构视窗、场景图层/检查器/状态，以及旧侧栏和“最近运行”组件。数据驱动的任务—反应—基因功能网络保留。
- `/records` 使用新增 `GET /api/v1/runs` 读取数据库历史，支持检索、状态/来源筛选、分页、打开实验和加入比较；新浏览器无需已有本地记录。此接口不新增删除动作。
- 旧 `/runs/:runId` 链接兼容跳转至工作台；旧结构页签回到响应概览。演示和结果保持同一运行编号。
- 实际提交检查发现旧合成包任务 CSV 为长表，与在线任务矩阵不同；现在对该预计算格式使用已校验的保存摘要，明确返回 `scope=top`。正常在线/预计算矩阵仍按全量协议读取，损坏产物继续报错。没有重新计算或修改旧科学产物。
- 修复复用参数时扰动输入框不同步；记录筛选与分页由 URL 保存，刷新读取已应用条件。
