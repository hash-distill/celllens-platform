# 代谢任务评分基因文案修正

日期：2026-10-21。

原任务卡片的“完整覆盖 · 1/1 个基因”“关联基因”容易被理解为相关生物过程只涉及一个基因。当前冻结数据库中的七项任务确实各登记一个不同评分基因，但这一登记范围不等于完整生物学关联。

覆盖范围页将状态、筛选、统计卡片和下载入口统一限定为“知识库评分基因齐全”；卡片基因列表改为“已纳入输入的评分基因”。每张任务卡片直接说明相关生物过程涉及的基因不限于此。详情页分别显示知识库评分基因总数和输入可用数量，并说明基因齐全不代表整条通路被完整覆盖或功能已验证。部分缺失及没有可用评分基因的任务也使用同一口径。

本次只修改展示文案和必要的换行样式；数据库、接口、身份映射、评分规则和结果数值沿用现状。

验证：前端生产构建包含 TypeScript 检查；现有 `scripts/check_coverage_frontend.py` 全流程通过。在正式服务 `http://127.0.0.1:8000` 逐项核对七张卡片及其详情，检查丙氨酸合成 8/28 的部分缺失场景、没有输入评分基因的空列表、两种主题与 1280/1440/1920px 窗口。页面无横向溢出、页面错误及写入请求，实验记录保持 7 条。证据与截图位于 `reports/task-scoring-copy-2026-10-21/`。未执行模型推理或后端全量回归。
