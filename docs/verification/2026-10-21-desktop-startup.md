# 桌面页面与启动性能验收

本次基于 `56fa69f`，保留已整合的 `new_frontend` 设计与本地系统逻辑。计时采集始于 2026-10-20，修改和最终验收在 2026-10-21 完成。原始结果位于忽略目录 `reports/startup-performance-2026-10-20/`。

## 变更

- 删除手机和平板宽高断点、安全区域、动态视口和触控专用样式，以及移动端页面元数据；桌面最小页面宽度为 1280px。浏览器检查改用桌面窗口。保留减少动画偏好、桌面弹性尺寸和图表尺寸监听。
- Windows 生产启动默认按内容指纹检查前端源码、配置、依赖锁、Node 环境及完整 dist 输出摘要；内容一致时复用构建，变化或输出损坏时重建。`-Rebuild` 强制完整构建，`-SkipBuild` 保留手动跳过行为，二者互斥。
- 细胞背景列表的就绪检查按文件身份、大小、纳秒时间戳及预期摘要缓存哈希结果；文件变化或消失时失效。真实实验提交和流水线仍调用未修改的 `verify_entry`，完整读取文件并计算 SHA-256。
- `scipy.stats` 延迟到实际计算秩相关时导入；计算公式保持原样。首页下方图片在接近视口时才设置背景地址，保留原始图片与设计。

## 本机计时

以下是单机采样，受磁盘缓存和并发负载影响，不表示所有机器的固定启动时间。浏览器使用新 Chromium 上下文、1440×1000、减少动画偏好；首屏网络稳定时间是 `networkidle`，不是整个系统就绪时间。

| 项目 | 修改前 | 修改后 |
|---|---:|---:|
| 全新 Python 进程导入 API 模块 | 6.237 秒 | 4.078 秒 |
| 连续细胞背景列表请求 | 2.697 / 2.688 秒 | 缓存命中 0.0718–0.0851 秒 |
| 首页首屏 PNG 传输量 | 9,661,467 字节 | 1,110,633 字节 |
| 首页首次内容绘制 | 1,832 毫秒 | 两次采样 616 / 468 毫秒 |
| 首页首屏网络稳定 | 3.394 秒 | 两次采样 1.397 / 0.928 秒 |

前端构建复用命令两次实测约 1.33 / 1.46 秒，跳过重复类型检查和打包；这不是完整启动时间。首次安装、输入变化及 `-Rebuild` 仍执行完整构建。缓存的第一次资产检查仍需完整哈希，预览服务首次背景查询 2.917 秒；不能将后续缓存时间描述为冷启动时间。

修改前接口来自已运行的 8000 主服务，修改后的分项计时与页面检查首先使用关闭 worker 的 8011 预览服务，其业务就绪状态会明确为不可在线提交。静态产物和科学资产相同；本次不提交新实验，不调用外部大模型。

## 首次覆盖页耗时边界

修改前首次 `GET /api/v1/coverage` 为 38.193 秒。独立新进程普通计时显示首次 scCellFie/数据库初始化约 23.45 秒，官方完整度计算约 15.67 秒；相同面板的进程内报告缓存已有复用。覆盖页按路由加载，不阻塞首页。此次保留官方算法、冻结数据库与每次请求的来源校验，没有宣称消除首次科学计算耗时。详细采样和剖析在 `coverage-diagnosis.md`、`coverage-timing.json` 与 `coverage-profile.txt`。

## 验证范围

- 生产构建、构建指纹回归、现有功能网络及预测证据工具检查通过。
- 桌面综合浏览器检查：1280 / 1440 / 1920px，亮暗两种主题，60 组页面与窗口组合；五张资源可读取、主题持久化与系统同步、历史记录及真实结果入口通过，无页面错误或 POST 请求。
- 首屏图片回归通过；滚动后八个下方图片容器均有背景，未遗漏设计图片。
- Ruff、BasedPyright、Git 差异空白检查通过。独立代码审查未发现阻断问题。

后端新增 3 项性能与校验边界回归均通过。全量最终结果为 **247 通过、1 失败**，失败项为未修改的 `test_staged_preparation_survives_atomic_publication`：准备完成后的外层目录 `partial.rename(root)` 在 Windows 上报 `WinError 5`。同一测试使用较短临时路径曾原样通过；恢复原先 eager scipy 导入的独立 probe 同样首次重命名失败，等待 0.25 秒后成功。观察支持短暂占用现象，但未定位持有句柄的进程，不能归因某个外部程序。没有添加测试跳过或重试，没有修改科学发布代码，也不声称全量回归通过。日志为 `pytest-final.txt`、`publication-shortpath.txt`、`publication-probe.txt`。

## 正式服务重启

确认活动在线任务为 0 后停止原 8000 API，并通过默认 `start_system.ps1 -StartLocalMysql` 启动。数据库复用、迁移、表结构及持久化往返检查通过，前端构建自动复用。重启后的 `/ready` 返回 200，数据库、worker、GPU 均为 true；四个背景就绪，历史实验数仍为 7，活动任务为 0。

正式服务重新测得首次背景查询 2.6188 秒，之后两次为 0.0620 / 0.0618 秒；首页首次内容绘制 508 毫秒，首屏网络稳定 1.246 秒，PNG 传输量仍为 1,110,633 字节。首屏与滚动图片检查通过，没有页面错误或 POST 请求。证据为 `primary-startup.txt`、`primary-after.json`、`browser-primary-after.json`。就绪检查和只读页面验证不等同于本轮重新验证 GPU 推理；本轮没有创建新科学实验。
