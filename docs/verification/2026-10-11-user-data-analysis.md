## 已知范围

个人数据入口提供账号归属校验，既有预设实验和 `/runs` 历史结果仍为共享入口。首期只接收人类 H5AD，不提供任意背景的 STATE 预测、通用 Ensembl 转换、显著性/因果推断、用户删除与配额回收、任务取消或集群调度。资源预检不等同于操作系统内存隔离，部署仍面向受控科研用户。

本机验收日志与浏览器截屏保存在被 Git 忽略的 `reports/user-data-acceptance/` 及相关 `reports/user-data-*.log`。启用正式账号与 CPU 服务见[用户数据指南](../guide/USER_DATA.md)。
