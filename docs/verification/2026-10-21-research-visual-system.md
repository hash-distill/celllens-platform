# 内页科研工作台视觉优化

日期：2026-10-21。

## 设计与范围

用户确认继续执行“冷白纸面、浅蓝灰背景、青绿点缀”的推荐方向。内页增加低对比渐变和仅在顶部出现的坐标网格，让页面、内容面与数据区域具备清晰层次。正文、表格和参数标签提高字号，数值使用等宽数字；按钮、边框和圆角统一，青绿色主要用于操作与选择状态。

通过 `App.vue` 的 `research-main` 类限定作用范围，新样式集中在 `frontend/src/research.css`。首页沿用既有背景与视觉设计，顶栏仍全宽、亮暗与服务状态靠右，AI 解读和设置保持停用。

- 实验工作台：有运行时压缩页头，突出当前实验；实验参数的两列结构与采样字段位置保持一致。
- 科研图：阅读指南移至图后，可展开；概览内隐藏重复标题，保留群体分布及非形态说明，主要图表更早进入首屏。
- 实验记录：字号提高、行距收紧、搜索区与状态区分层，保留检索、分页和比较操作。
- 方法数据：方法、架构图与模型输入输出形成论文式内容区；背景和覆盖目录使用统一中性表面。
- 服务状态、比较和使用说明同步继承新的内页表面和排版。深色模式使用蓝灰层级，图表和科学输出保持既有来源语义。

本轮只调整展示，没有改变预测、基因筛选、评分、知识库、降维或导出数据逻辑。没有引入外部字体、页面大背景图片或动画依赖。

## 验证

- 前端类型检查与生产构建通过。
- 综合浏览器检查：1280／1440／1920px、亮暗两种主题，共 72 组页面／窗口组合通过；页面错误和 POST 请求为 0。
- 首页源文件和配色变量保持一致，1440×1000 浅色首页首屏像素比较无差异。
- 在相同窗口下，表达科研图顶端位于约 727px，进入首屏；阅读指南展开／收起正常，实际下载的表达 JSON 与修改前完整响应相等。
- ALDOA 记录检索与四条已完成实验的本地比较通过，三个桌面宽度均无页面横向溢出；没有提交新实验。
- 方法数据专项检查 10 项通过：两张架构图的键盘／放大／下载交互、四背景切换、完整表达面板 CSV、中文搜索、任务覆盖可视化、旧地址跳转与错误重试。页面错误和写请求为 0。
- 5 条实验记录及 135 个保存产物文件的 SHA-256 与修改前一致；本轮专门检查页面错误、写请求和助手请求均为 0。

本轮未运行模型推理或后端全量测试，不把界面验收描述为生物学预测验证。

## 证据

`reports/scientific-visual-direction-2026-10-21/` 保存：

- `source-before/` 与 `baseline.json`：修改前文件、实验记录及产物哈希。
- `*-current.png` 与 `*-after.png`：初始方案前后实际页面；`workbench-final.png` 为最终紧凑页头结果。
- `home-before.png`、`home-after.png`：首页像素核对。
- `theme/acceptance.json` 与截图：72 组主题和布局检查。
- `focused-acceptance.json`：首页、首屏图表、阅读指南、真实 JSON、检索、四实验比较及数据保留核对。
- `expression-source.json` 与 `expression-export.json`：同一已保存实验的原始响应与下载结果。
- `coverage/`：方法图、数据目录、中文搜索与导出检查。

设计参考：[CZ CELLxGENE 的表达探索说明](https://cellxgene.cziscience.com/docs/04__Analyze%20Public%20Data/4_2__Gene%20Expression%20Documentation/4_2_1__Get%20Started)用于参考以真实表达数据为中心的组织方式；[W3C 颜色使用说明](https://www.w3.org/WAI/WCAG21/Understanding/use-of-color.html)用于核对来源同时使用颜色、文字与点形标识。视觉取舍依据本项目当前页面，不移植第三方科学计算或业务流程。
