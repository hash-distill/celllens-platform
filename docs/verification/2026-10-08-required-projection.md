# 每次完成实验必须具备二维投影

日期：2026-10-08。修复用户报告的预计算演示 `HTTP 404 / ARTIFACT_NOT_FOUND`，覆盖新实验与已有记录。

## 实现

- 预计算包必须在 manifest 中登记 `projection.json` 的哈希；读取和创建前验证非空点集、有限坐标、有效来源、细胞序号以及对照/预测两类群体。缺失、未登记、空结果或损坏投影不能进入完成状态。
- 在线与匹配验证链路在发布前校验同一投影契约，并要求投影列入正式产物清单。缺失投影报科学契约错误，不再标记完成；不完整的缓存不会被复用。
- 新合成包保存 `demo_cells.npz`（基因顺序、合成对照和扰动后表达矩阵），对两个来源执行同一固定种子的随机投影。每组 512 个细胞，共 1024 个点；无真实观测时不增加观测群体。
- 合成输入从演示包的保存表达值出发，用固定种子的零均值噪声生成单细胞异质性，再以 expm1 转成非负计数，应用既有归一化、log1p 与随机投影协议。其用途为展示交互，不是恢复历史原始细胞，也不是 STATE/scCellFie 的科学输出。
- 已对 9 条历史预计算记录新增矩阵、投影及独立来源文件，并登记数据库产物。原运行 manifest、摘要、表达、代谢及覆盖文件的 SHA-256 全部保持不变。演示包自身的 manifest 更新前已保存备份；历史投影保存原 manifest 哈希与新增矩阵哈希。
- 页面明确展示“合成对照群体 / 合成扰动后群体”，说明矩阵来源和历史补充，不将点序号解释为同一物理细胞的前后配对。
