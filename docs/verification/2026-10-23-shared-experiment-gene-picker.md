# 实测与预测共用实验选择控件

日期：2026-10-23。

## 实现

- `CellBackgroundPicker.vue` 提供相同的四背景单选卡片；`GenePicker.vue` 提供功能分类、可搜索候选、双语基因注释、分类说明与键盘选择，两种实验共同使用。
- 修正 `research.css` 中原本只应用于预测表单的样式，使字号、内边距和圆角应用于共用控件。实测参数区采用相同的列间距与外边距。
- 实测候选通过 `GET /api/v1/catalog/perturbations?cell_line=...&mode=measured` 返回完整固定源候选，使用现有 PANTHER/HGNC 分类快照；不再只读取前 100 个候选。预测保留原模型支持列表与就绪检查。
- 实测目录读取失败可重试；实测提交仍核验所选基因在目录内、固定源覆盖、采样上限和种子。GPU 或模型词表不限制已确认数据的实测分析。
- 切换背景清空旧分类与基因；候选支持分类内搜索、方向键、回车与鼠标选择；无效自由输入恢复到已选值，输入框内回车不触发实验提交。
- 分类计数按当前背景及实验类型的候选集合计算，一个基因可属于多个类别，两个类型的候选数量允许不同。
