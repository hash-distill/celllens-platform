# 无需账号的上传分析验收

当前上传入口采用共享科研工作区。进入 `/datasets` 即可上传，无登录、注册、默认账号或浏览器身份 Cookie。能访问受控部署的人可查看共享数据、创建分析、下载文件和归档；旧账号数据不自动公开。

## 验收结果

- 全量后端测试 161 项通过，9 条上游弃用/AnnData 提示；Ruff、basedpyright、前端类型检查和构建通过。
- 浏览器直接进入上传页面，完成真实 H5AD 上传、名称搜索、任务命名、分组与参考组选择、CPU 分析、PCA 和代谢结果、CSV/JSON 下载、数据集/状态筛选、归档。没有页面脚本错误、账号接口请求或登录 Cookie。
- 第二个全新浏览器上下文可读取共享源文件和完整报告；390、768、1,280px 宽度没有页面横向溢出。`/login` 旧地址直接跳转上传页面。
- 单独延迟旧筛选响应，在切换到“已完成”后再释放“失败”列表，当前显示仍保持正确。
- 后端验证跨站写请求拒绝、请求体限制、HDF5 与表达尺度校验、结果/源文件 SHA-256、归档保留、全局三个待完成任务上限及任务恢复。
- 旧账号归属的数据与任务保留在数据库，但共享列表和源文件/报告/结果下载均不返回旧私有记录。
- MySQL 升级到 `0003_shared_workspace`，完整表结构和运行读写检查通过，`alembic check` 无差异。SQLite 测试从旧结构保存账号、数据与任务后升级，验证记录与归属保留；无共享记录时可降级再升级，有共享记录时明确拒绝危险降级；运行读写与结构检查通过。

验收使用独立 SQLite 工作区和工具托管的本机进程，未替换现有运行服务。证据保存在被 Git 忽略的 `reports/shared-upload-acceptance/` 和 `reports/no-login-*.log`；真实数据与结果不提交到 Git。

正式启用需要部署当前代码、执行迁移、设置 `CELLLENS_DATA_WORKER_ENABLED=true` 并重启，不再创建管理员账号。输入格式、管理规则和当前范围见[用户数据指南](../guide/USER_DATA.md)。
