# 首页、服务入口与任务覆盖展示调整

日期：2026-10-21。

- 首页主标题从 82px 调整为随桌面宽度变化的 52–60px，两行展示；同步调整行距、字距及正文大小。
- 顶部服务状态入口与导航统一为 12px，增加点击、悬停和键盘焦点样式。新打开的页面可正常进入服务状态；另以路由资源失效的受控场景复现旧页面点击后停留原处的问题，并补充一次整页导航恢复。持续失败时限制为一次恢复，避免循环刷新。正常导航保留原来的路由行为。
- 覆盖范围页仅保留一组标题与简洁的输入背景信息，原来的共享 STATE 输出面板介绍合并至标题下方。数据库版本继续保存在来源详情和下载数据中。
- 按用户后续要求恢复“关联基因”，默认显示完整或部分覆盖的任务，排除没有输入关联基因的任务；基因详情中的关联任务也包含部分覆盖项。当前正式接口对应 150 项任务，其中完整覆盖 7 项、部分覆盖 143 项。统计、筛选、搜索、详情与 JSON 导出使用一致的范围。
- 新增轻量任务覆盖圆点图，每个圆点对应实际任务，填充比例取自知识库关联基因覆盖率；点击同步详情及列表分页。图示表达输入可用性，页面保留知识库关联范围不穷尽生物学关联的说明。

本轮修改前的当前源码保存在 `reports/ui-refinement-2026-10-21/source-before/`，保留工作区已有改动。没有修改后端接口、数据库、模型或科学结果，没有执行推理。

## 验证

- 前端 TypeScript 检查与生产构建通过；两个相关 Python 验收脚本 Ruff、BasedPyright 通过。
- 先在旧生产构建确认标题/入口字号及覆盖范围检查失败；单独复现路由资源失效时点击无法完成导航，随后验证修复结果。
- `check_header_navigation.py` 检查三种桌面宽度下的标题两行排版、导航字体一致和真实服务状态页进入；受控资源失败验证恢复成功与持续失败时的一次恢复上限。
- `check_coverage_frontend.py` 检查现有方法数据导航、真实接口数量、完整/部分筛选、搜索、圆点图选中与跨页详情、不同面板响应夹具、历史链接及失败重试。可见任务 150 项，页面错误及写入请求均为 0。
- 首页和任务页面各检查浅色/深色与 1280/1440/1920px，共 12 组布局，无横向溢出；另实际下载 JSON，确认仅含 150 项有输入基因覆盖的任务。实验记录保持 7 条。
- 证据、报告与截图位于 `reports/ui-refinement-2026-10-21/`。检查基于当前正式服务 `http://127.0.0.1:8000`，未运行后端全量回归。

重复检查：

```powershell

python scripts/check_header_navigation.py --output reports/ui-refinement-2026-10-21/header

```
