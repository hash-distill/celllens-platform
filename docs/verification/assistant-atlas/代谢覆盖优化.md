# 代谢覆盖页面验收

本轮将数据图谱中的“功能覆盖”统一更名为“代谢覆盖”，同步更新栏目入口、页面标题和相关链接。

## 内容与交互

当前真实模型面板包含 2,000 个表达基因，其中 138 个对应知识库登记的 931 个代谢基因。页面显示全部 218 个代谢任务：完整覆盖 7、部分覆盖 143、未覆盖 68、未登记关联基因 0。未覆盖与未登记分别解释，不推导为不存在代谢功能。完整覆盖的关联反应为 86 / 787。

目录使用五分钟、最多四个来源的内存缓存，不写入浏览器持久存储。实验来源与模型来源隔离；保留读取时间、主动刷新、加载骨架、等待秒数、取消与重试。刷新失败保留旧快照并明确标示。大响应使用浅层响应式状态，避免对全目录做深层代理。

## 实测

本机接口 http://127.0.0.1:8028/api/v1/coverage：

| 请求 | 传输字节 | 单次耗时 |
| --- | ---: | ---: |
| 未压缩、持久快照命中 | 1,266,548 | 0.460432 秒 |
| gzip 压缩、持久快照命中 | 107,353 | 0.500578 秒 |

传输体积减少 91.52%；解压后逐字节、JSON 内容均一致。响应保留 Cache-Control: no-store，压缩响应设置 Vary: Accept-Encoding。本次优化降低传输量，不宣称这两次本机测量证明服务端延迟降低。

真实浏览器验证：

- 从模型与方法栏目返回代谢覆盖，新增目录请求为 0；主动刷新新增 1 次请求。
- 六种筛选及完整任务数量正确；未覆盖任务展示缺失范围和解释。
- ACAA1 → 花生四烯酸降解 → ACAA1 双向导航正常。
- 模拟延迟和网络失败：取消、重试成功；刷新失败仍保留旧目录并标记失败。模拟仅用于浏览器交互验收，不改真实服务或研究数据。
- 混合 run 与 cell_line 参数被明确拒绝，不展示其他来源的目录。
- 1440×1000 桌面、390×844 手机及深色主题截图已保存；手机文档宽度与视口同为 390，无横向溢出。

## 验证结果与范围

- 前端 79 项测试通过，类型检查及生产构建通过。
- 后端 35 项集成与压缩测试、19 项目录与缓存测试通过，共 54 项。
- API 重启后 ready=true，CPU 和 GPU worker 在线，分析和预测能力就绪。本轮没有重新运行扰动预测或修改实验结果。
- 首次无有效快照的科学构建仍需约 40 秒；没有跳过官方计算和来源校验。当前服务已预热。
