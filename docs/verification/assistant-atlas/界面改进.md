# 科研助手与数据图谱改进

## 科研助手

借鉴 [Open WebUI 的聊天交互](https://docs.openwebui.com/features/chat-conversations/chat-features/)与 [LobeHub](https://github.com/lobehub/lobehub)的上下文组织方式，以本项目的科研结果为中心重新设计，没有引入整套聊天平台或额外前端依赖。

- 在抽屉内检索、选择真实已完成结果，显示实测或预测来源；也可跟随结果页当前指标与视图。
- 预览后台核验的结果摘要后发送；快捷问题、固定输入区、任务选择与模型设置处于同一个工作流中。
- 同一摘要下支持连续追问，最多携带最近六轮已完成问答。切换来源或视图隔离会话，摘要哈希变化时清空不匹配的历史。
- 提供停止等待、失败重试、重新生成、复制正文，以及带来源摘要和实际历史问答的 JSON 导出。
- 安全显示 Markdown 标题、列表、加粗、代码及表格；模型输出中的 HTML 保持普通文本。
- 前端和后端共同校验历史规模、上下文预算与请求大小。凭据不写入解读导出。

会话保存在当前页面内存中，刷新页面后清空。停止等待不保证供应商已经停止计算。模型配置是否可用、实际输出质量仍取决于用户选用的服务；本次验收没有调用外部付费模型。

## 数据图谱

四个栏目调整为：

| 栏目 | 要回答的问题 |
| --- | --- |
| 数据与扰动 | 这个背景与基因组合，有哪些可分析的数据和模型入口？ |
| 细胞与样本 | 细胞背景、真实对照、预测采样和表达面板分别是什么？ |
| 模型与方法 | STATE 与 scCellFie 分别完成什么，结论能支持到哪一步？ |
| 功能覆盖 | 输入面板覆盖了哪些代谢基因、反应和任务？ |

统一绿色背景、编号导航与页面标题；总览指标前置，筛选集中排列；目录表固定表头并保留横向滚动。细胞页增加样本卡片和结构插图，方法页突出分析路径，覆盖页强化基因、任务和详情联动。

保留真实接口、来源版本、筛选、下载和公开只读边界。覆盖率仍表示输入可用范围，不等于预测准确率或生物学验证。

## 验证

- 前端回归：67 项通过，包括连续追问、重试、取消、历史隔离、请求限制、Markdown 安全显示及导出追溯。
- 前端生产构建及 TypeScript 检查通过；既有 Three.js 大资源块提示仍存在。
- 后端助手相关测试：129 项通过，使用模拟供应商传输；详细命令见 `backend-verification.md`。
- 浏览器检查：四个栏目在 1440 和 390 像素宽度均无页面横向溢出、无错误提示，标题与导航状态对应。
- 对话浏览器验收：真实摘要读取；模拟回复验证首轮、连续追问、摘要哈希绑定、表格显示、HTML 不执行、下载、取消、来源切换和失败重试。导出包含一轮实际历史，摘要哈希一致，无 API Key。
- 交互验收：K562／ALDOA 查询返回 77 个本源实测细胞，并带入正确研究参数；细胞背景切换、基因详情随筛选更新、完整覆盖任务筛选（7 项）和深色模式通过。

浏览器脚本、结果日志及截图位于 `output/playwright/`。其中含 `mock` 的截图和导出是界面验收数据，不是实际模型科研结论。所有原始研究结果保持不变。
