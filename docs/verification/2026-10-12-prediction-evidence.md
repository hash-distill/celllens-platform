# 模型预测结果的展示标准

用户确认：保留完整模型预测变化，明确标为预测；隐藏缺失和纯关联。

## 已实现

- 响应概览、基因响应、代谢任务、反应表和功能任务选择器共用筛选：对照、预测和差值均为有限数值，差值非零。零基线或零预测值本身仍有效，不填补缺失。
- 结果明确标为模型预测；非零变化不表示统计显著性、已验证生物学效应或因果贡献。
- 关联名单和关联图从本次完整冻结追溯筛选：任务、反应、基因都有有效预测变化才显示链路；未评分名称、原始 GPR 中的缺失名称、未验证驱动归因不展示。不从现行知识库补写历史结果。
- 无扰动后实测时不显示空观测列；基因详情仅显示该基因实际存在的观测字段。
- 基因 CSV 和关联 JSON 与页面采用同一筛选；不存在实测时 CSV 不导出空观测列。原始文件、数据库记录、清单和哈希保持不变。
- 逐细胞指标选择器与上述有效结果取交集，所选图表指标还需群体逐细胞数值完整。PCA/UMAP 的坐标计算与原始输入保持原方法。
