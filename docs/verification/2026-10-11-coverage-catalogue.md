# 独立模型覆盖目录验收

日期：2026-10-11。本机服务：`http://127.0.0.1:8000`。

## 变化

首页新增“当前模型覆盖哪些代谢基因与任务？”入口，打开独立 `/coverage` 页面。实验概览、代谢表格和功能网络不再重复展示官方完整性面板；需要详细范围时，从实验链接进入对应保存来源。

目录提供全部代谢库基因与任务，默认查看已覆盖基因或完整覆盖任务；支持缺失项、部分覆盖、功能分类、名称/HGNC/关联基因搜索、每页 20 条及可选条数、基因—任务联动、全量 CSV/JSON 下载。任务明细列出全部已覆盖与缺失关联基因。手机端和深色模式保持可用。

`GET /api/v1/coverage` 校验登记面板、HGNC 身份和冻结数据库，使用 scCellFie 官方统计，按面板及数据库清单缓存。模型来源不创建实验或执行扰动预测。`run_id` 读取该实验已保存报告与实际输入，不将当前模型范围应用于所有数据；不同数据库版本返回明确错误，报告 ID 和文件哈希须一致。

## 当前数据核验

四个当前注册模型使用相同的 2,000 基因面板。浏览器逐个切换 K562、RPE1、Jurkat、HepG2，核验代谢库已覆盖 138 / 931 个基因、完整覆盖 7 / 218 项任务、完整覆盖 86 / 787 个反应。任务目录另包含部分覆盖和未覆盖项；完整覆盖任务数不等于可评分任务数，统计不表示准确率、激活或通量。

真实保存来源使用 `run_f4a6276b0aff42aa`；下载 JSON 保留该来源和全部 218 项任务、787 个反应。读取检查前后服务器实验记录总数保持一致。
