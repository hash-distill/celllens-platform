# 评审修复清单

三位独立评委分别完成产品体验、科研真实性和细胞展示评审。评审时未继承此前实现对话，使用运行中的系统、接口与源码核查；报告保留修复前证据。本清单由主代理作实施取舍，最终结果另见验收记录。

| 领域 | 接受的修复 | 验收依据 |
|---|---|---|
| 入口 | 两项任务：实测数据分析、基因扰动预测；公开/自有作为实测来源 | 旧深链、输入条件、提交核对仍可使用 |
| 页面 | 保留绿色视觉，统一工具条安全区与字号，业务页查询前置 | 常见桌面/窄屏真实页面无遮挡、无正文横溢 |
| 导入 | 真实受控目录、准备说明、字段示例 | 私有可操作，公开不泄露路径，不虚构上传能力 |
| 研究总览 | 研究摘要和数量先出现，结构与投影辅助阅读 | 同一运行的群体和来源可在首屏判断 |
| 细胞结构 | 真实缩放/复位/二维降级；仅 ER/Golgi 显式知识分类导航 | 导航打开同一记录任务，未注释结构不臆测定位 |
| 表达投影 | 筛选固定轴域，显示可见数/总数、细胞身份与冻结参数 | PCA/UMAP 群体切换不改变比较标尺 |
| 实测任务 | 任务→反应→基因/缺失成员只读追查 | 数据版本与每个关联文件哈希一致，零与缺失分别保留 |
| 预测契约 | 原群体与匹配群体分列，比较可用性与真实产物一致 | 统一来源、证据抽屉、导出不矛盾 |
| 统计诊断 | 保留原指标，增加明确准备的批次等权敏感性 | 已有 Jurkat 案例原比值 0.936、等权约 1.143；不改历史产物 |
| 功能诊断 | 比较自身覆盖分层、有限成对任务数量、缺失信息 | 不把低覆盖派生任务或重复均值当独立功能验证 |
| 统计解释 | 细胞级 DE、分母、非独立重复和非留出说明靠近指标 | 不以预测样本数增加生物证据 |
| 导出 | 明确阅读报告/完整包/CSV/研究笔记用途，保留完整比较指纹 | 下载内容、当前研究身份与元数据一致 |

## 本轮取舍

不另训大模型，不伪造细胞形态、4D 时间轨迹、代谢通量或实验验证。结构模板保留为可操作的知识导航；结果是否有用由真实来源、效应、覆盖和敏感性共同呈现。

保留所有已完成计算和已有笔记。新的批次诊断使用独立版本与来源绑定，不能覆盖当时的预测或比较统计。公开部署继续遵循已发布结果白名单，不能因演示方便开放私有路径和计算接口。

先完成独立模块修复，再由主代理检查实现、执行回归、重建本地服务、浏览器验收和打包。工程验收不等于独立科学泛化验证，也不等于未提供目标主机上的 Linux/HTTPS 部署验收。
