# 细胞展示评审

评审视角：首次接触 CellLens 的全国 AI 竞赛评委，重点看结构细胞、表达空间和功能证据能否形成可信、可操作的研究流程。

**结论：结构展示完成度不错，真实科研价值主要来自表达比较和冻结证据，当前三者仍偏并列陈列。最优先修复的是群体切换时的坐标尺度变化；随后补齐实测任务证据和选择上下文。无需增加虚假时间轴、从 RNA 推断形态，或用细胞器发光表达未经验证的活性。**

## 发现

### C1 · P1：群体筛选改变坐标尺度，削弱同图比较

**实际复现：** 进入主记录的研究总览，PCA / 全部群体时，两轴可见范围约为 x = −10～40、y = −20～30。点击“扰动实测”，范围自动变为 x = −2～4、y = −1.5～1.5。拟合坐标没有重算，但图像的视觉尺度变了，小范围点群会被铺满画布。

**定位：** `frontend/src/components/ResearchCanvas.vue:38–41`：两轴只有 `scale:true`，没有全体坐标的固定边界；筛选直接删除另一群体的 series。`frontend/src/components/MeasuredProjection.vue:18–21` 的表达响应图也未设置全局边界，属于同类源码风险，后者未在本次逐项实测。

**价值损失：** 评委快速来回切换时容易误读群体离散程度与位置关系；图下注明“不代表显著性”不能消除比例尺变化带来的视觉误导。

**修复建议：** 用同一投影全部有限坐标计算并缓存 x/y 边界，默认固定两轴，只改变群体可见性；提供明确的“适应当前群体”可选动作，启用时显示“当前群体独立缩放”。双轴缩放应使用一致的过滤规则，避免缩一轴意外改变另一轴范围。群体切换不得重拟合。验收时记录全部/对照/扰动三种状态的轴上下界，默认应一致。

### C2 · P2：细胞器选择只换说明，尚未成为研究导航

**实际复现：** 首页点线粒体只增加名称；结果总览点线粒体或高尔基体只改变高亮和一段结构边界说明，右侧投影及下面任务分类不变。切换 PCA/UMAP 还会清除结构选择。

**定位：** `frontend/src/views/HomeView.vue:69` 未监听结构选择；`frontend/src/components/ResearchCanvas.vue:12–27,47` 的选择仅是组件局部变量，没有向任务视图发出研究选择。

**价值损失：** “进入细胞，理解研究问题”在演示中更像装饰入口。它在科学表述上克制，但研究者点选后无法继续核查。

**修复建议：** 先实现可审计的“知识库功能分类导航”。冻结 `Task-Info.csv` 明确有 `Processing in the ER`（5 项）及 `Processing in the Golgi`（6 项）；示例行见 `data/registry/sccellfie/human/Task-Info.csv:22,24,57,65,69,70,114,118,119,121,150`。实测分类已有哈希和版本校验（`backend/app/services/measured_results.py:97–125`）；预测链条已有冻结分类（`backend/app/services/task_trace.py:34–45,63`）。只匹配这些显式分类，列出当前记录实际有分数的任务、原始分类、覆盖状态与知识库版本，再跳到同一记录的任务证据。

线粒体不能仅凭 `ENERGY METABOLISM` 词义映射；细胞核、细胞膜、细胞质没有明确收录时显示“此结构暂无显式收录的功能分类”。标注“关联来自知识库任务分类，不是本次定位或细胞器活性测量”。也可直接将入口称为“功能分类导航”，不要暗示完整亚细胞定位图谱。

### C3 · P1：实测“查看该任务证据”只到分数表，无法核查成员链

**实际复现：** 总览选择“甘氨酸转化为丙酮酸”→“查看该任务证据”。页面切到功能证据并筛出一个英文任务行，显示对照 0.52328、扰动 0.68076、差值 0.15748、覆盖 100%；没有出现关联反应、GPR/基因成员、缺失成员及其输入值。

**定位：** `frontend/src/views/MeasuredAnalysisView.vue:78–83` 只做 tab 切换及表格检索；`:260–268` 提供任务/反应两个平行表；`frontend/src/components/ResultOverview.vue:150` 的按钮文案承诺“证据”。

**价值损失：** 100% 覆盖只说明输入完整度，不能回答“哪些基因/反应支撑这项分数”。评委需要离开界面自行拼表，核心的可追溯科研价值无法现场展示。

**修复建议：** 给实测结果提供与其冻结知识版本一致的任务详情：任务定义 → 关联反应 → GPR/基因成员 → 对照/实测输入 → 缺失状态。保留原始 ID、版本和哈希，评分规则只按实际实现说明，不将成员关联称作因果归因。短期如果尚无可验证的逐成员产物，应将入口改为“查看任务评分”，并明确说明当前证据深度；不能临时读取最新知识库补成历史结果的证据。

### C4 · P2：投影的当前选择没有进入证据上下文

**实际复现：** 先查看上述任务，再回研究总览，选择 UMAP / 扰动实测，打开“来源与证据”。抽屉仍显示“当前证据层：细胞结构示意”，选中任务仍为 `Conversion of glycine to pyruvate`；没有 UMAP 或扰动群体信息。界面声称保存时会绑定当前选择，但本次没有执行保存。

**定位：** `frontend/src/components/ResearchCanvas.vue:12–13,26–27` 将 embedding/group/structure 保存在局部；`frontend/src/views/MeasuredAnalysisView.vue:33–34` 只按 tab 推导 layer 和旧指标；`frontend/src/components/ResearchEvidence.vue:24–25,45` 使用父级 selection。`frontend/src/types/research.ts:2` 已有 `group_id`、`projection_id`，但这里没有填充。

**价值损失：** 用户对某个投影或群体写下的判断，保存后可能缺少真正的查看条件；旧任务的留存还会让评委以为任务与当前点群存在计算联动。

**修复建议：** 建立结果级选择状态，由投影显式发出 embedding、group、layer、必要时 region/category；抽屉直接显示当前选择及仍保留的任务上下文。区分“当前正在查看”与“之前固定的任务”。切换记录应清空，切换标签应按明确规则保留；保存前显示可读预览。只读验收可先验证抽屉，无须为检查而写笔记。

### C5 · P2：表达点丢失身份，图不能支持逐细胞核查

**源码确认，浏览器界面一致：** 总览只提供群体筛选和坐标图，没有逐点详情或选择入口。tooltip 实现仅群体名和 x/y，series 将每个点降成 `[x,y]`，无点选事件。

**定位：** `frontend/src/components/ResearchCanvas.vue:11,37,41–43`；表达响应页 `frontend/src/components/MeasuredProjection.vue:16,21` 同样只保留坐标。后端已经验证群体内唯一身份并返回 `cell_id`/`cell_index`（`backend/app/services/research_projection.py:50–57`），实测坐标本身来自 obs_names（`backend/app/services/measured_analysis.py:90–97`）。

**价值损失：** 用户看到离群点时不能识别它、定位输入记录或保存一个可复核的子集。视觉交互尚不能回答具体研究问题。

**修复建议：** 保留组合身份 `(source, cell_id)`，hover 展示身份、群体、坐标、来源；点击打开只读详情并允许复制身份。若做框选，报告子集数和选取规则，保留原始行身份与投影版本。基因着色只可读取与同一批细胞身份严格对齐的真实特征产物，没有产物时明确不可用；不能拿默认基因色值冒充当前指标，也不跨群体硬配对细胞。

### C6 · P2：结构说明承诺缩放，但三维没有用户缩放实现

**浏览器与源码证据：** 结果页文字为“旋转、缩放或点选结构”；暂停、拖动旋转、2D/3D 切换均可执行，但控件只有暂停、重置、二维视图。源码中只有拖动旋转和按容器比例设置相机距离，没有 wheel/pinch、加减按钮或 zoom 方法。

**定位：** `frontend/src/components/ResearchCanvas.vue:47`；`frontend/src/components/CellScene.vue:94–100`；`frontend/src/lib/cellScene.js:254–260,284–307`；`frontend/src/lib/cellScene.d.ts:2–7`。

**价值损失：** 结构细节较小时，评委会尝试缩放却无从操作，降低功能可信度。缩放本身不会增加科研证据，但可以改善结构导航。

**修复建议：** 最小改法是删去未实现的“缩放”。如保留能力，增加带范围限制的加/减/复位按钮，并用相机距离或正规的相机控制实现；保留触屏纵向页面滚动，避免滚轮无提示地被画布吞掉。选择、暂停状态不应因 2D/3D 切换而意外丢失。键盘至少可完成选择、缩放、复位；不必强求完全自由的相机飞行。

### C7 · P2：图下注释不足以解释当前显示量和降维信息

**实际复现：** 筛成仅扰动实测 16 个点后，页脚仍写“32 条坐标”。它没有标明总数/当前可见数的区别。PCA/UMAP 只显示内部方法字符串，不展示 PCA 解释方差、特征数、预处理及 UMAP 参数。

**定位：** `frontend/src/components/ResearchCanvas.vue:11,51`；后端适配器已有 `counts/displayed_counts/total_cells/gene_count/input_units/provenance`，前端未利用（`backend/app/services/research_projection.py:72–90`）。原始实测投影写有 PCA 方差或 UMAP 参数（`backend/app/services/measured_analysis.py:260–275`），但适配响应没有传递这两类字段。

**价值损失：** 32 条容易被读成当前群体样本数，且评委无法判断二维投影展示了多少变异、用了哪些特征。方法名和哈希虽可查，解释成本仍过高。

**修复建议：** 图旁显示“当前显示 16 / 已保存坐标 32；本组总细胞 16”，未知总数保留未知。折叠的“投影方法”面板展示特征数、输入尺度、拟合群体、PCA 对照解释方差或 UMAP 参数、固定坐标的来源指纹。只透传冻结产物已有信息；没有记录则写“未记录”，读取时不重跑降维补齐。预测图必须把模型预测和真实观测在标题及图例中同时分开。

### C8 · P2：总览投影有隐藏缩放，但没有显式恢复与操作提示

**源码确认：** 总览配置了两个 inside dataZoom，却没有滑条、复位按钮或操作说明。表达响应页已有 slider 和“重置缩放”工具，形成同一种图两套交互的落差。

**定位：** `frontend/src/components/ResearchCanvas.vue:40,48–51`；`frontend/src/components/MeasuredProjection.vue:17,20,27`。本次未用脚本注入图表动作，也未据此宣称所有鼠标/触摸缩放场景均已实测。

**价值损失：** 用户误触后可能以为细胞消失或数据变化；恢复方式只能靠切群体/切方法间接重建，操作对键盘用户不可发现。

**修复建议：** 共享一套投影交互工具条：放大、缩小、恢复完整范围、当前缩放状态；将“滚轮缩放、拖动平移”作为可见短说明。恢复只重置视窗，保留方法、群体与数据身份。两个投影入口使用相同的坐标边界策略和工具语义。

## 已完成的亮点

1. **科学边界在主界面可见。** 结构、RNA 派生分数、实测与预测均有明确区分；来源抽屉说明细胞记录不是独立生物学重复、不证明泛化。没有把三维结构说成实测形态或模型生成影像。
2. **不是纯截图外壳。** 实际 3D 加载、按钮选择、暂停、拖动旋转、二维选择及返回三维可执行；PCA/UMAP 切换读到了不同的真实结果方法，任务跳转确实绑定同一分析 ID。
3. **数据缺失处理方向正确。** 后端拒绝无哈希、未知方法、随机投影、非法坐标和缺少群体身份的输入；GET 读取冻结产物，不即时生成替代点云。出处见 `backend/app/services/research_projection.py:1,13–35,43–71,94–148`。这是源码证据，未人为损坏数据验证。
4. **结构存在降级基础。** WebGL 创建失败或 context loss 会转二维；二维仍保留同名分区按钮。源码见 `CellScene.vue:39–72,79–100` 与 `cellScene.js:310–328`。本次验证了手动二维切换，没有强制触发 GPU/context 故障。
5. **已有节制的资源管理。** 像素比上限、低功耗偏好、实例化粒子、约 32 ms 渲染门槛、不可见/后台跳过绘制及卸载释放都在源码中。暂停后仍保留 RAF 调度，可后续改按需唤醒，但未测得实际性能故障，不应夸大为内存泄漏或卡顿。移动端有单列和按钮折行样式，不过只能算静态准备，不能写成移动实机验收通过。

## 可执行的改进次序

先固定坐标尺度并补当前显示数；再修正投影上下文、给总览加复位和方法说明；随后打通 ER/Golgi 的显式分类导航以及实测任务成员证据。最后做小屏和性能验证：360/390 px 宽度、触屏滚动/选择、键盘操作、reduced-motion、无 WebGL、切换多次后的资源释放。真实降级测试应在隔离浏览器会话或测试环境中进行，保留已有产物。

建议下一轮演示围绕一个可复核问题：选定一个任务 → 看同尺度组间分数 → 查关联反应/基因与缺失项 → 查看对应表达记录 → 保存带方法、群体、任务及来源指纹的研究笔记。这个闭环比继续增加细胞动画更能体现软件创新与科研价值。
