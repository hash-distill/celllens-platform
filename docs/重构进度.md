# 重构进度

本版按已确认的系统与交互方案完成，分支为 `codex/celllens-national`。开发与验收使用独立副本；原项目、历史结果和原始资产保持原样。原版补丁与文件清单保存在[验收目录](verification/national-refactor/)。

## 实现状态

| 工作 | 状态与依据 |
|---|---|
| 四个全局入口 | 研究概览、研究工作台、数据图谱、实验记录已接真实 API |
| 四个结果视图 | 研究总览、表达响应、功能证据、实验对照已贯通实测与预测结果 |
| 统一结果契约 | 标注来源、背景、目标、组别、单位、覆盖、模块可用性与来源清单；历史产物只读 |
| 真实投影 | 读取通过来源与哈希核验的已有派生产物；缺失或不可信时明确不可用 |
| 功能证据 | 跨任务按覆盖、分类与名称组织，同一任务内比较组别；实测分类匹配冻结知识库版本 |
| 研究发现与导出 | 数据库持久化，绑定具体记录和清单指纹；公共导出剔除私人发现与本机输入路径 |
| 受控 H5AD | 本地/私有根目录限制、表达尺度与组别预检、资源上限、完整分母计算；仅实测分析 |
| 独立 worker | CPU/GPU 独立进程、租约与 attempt、取消、中断恢复、实际心跳与依赖探针 |
| 访问边界 | 回环本地、单工作空间私有认证、白名单公共只读；公开模式禁用计算与写入 |
| 本地部署 | SQLite 启动、数据库迁移、独立 API/worker、进程身份核对后的停止已验收 |
| 页面验收 | 桌面浏览器覆盖四入口与结果页；截图归档至[页面截图](screenshots/README.md) |

## 最终回归

- 后端完整回归 **518 项通过**，8 条警告，耗时 270.94 秒；机器可读报告：[backend-tests.xml](verification/national-refactor/backend-tests.xml)。
- `backend/app`、新增测试与历史导入脚本的 Ruff 检查通过。
- 前端类型检查通过，生产构建通过，转换 804 个模块。
- [7 项相关前端验证脚本](verification/national-refactor/frontend-tests.json)通过，其中 national 验证 16/16、records 验证 8/8；预测证据检查脚本为 `check-prediction-evidence.mjs`。
- Windows 停止脚本处理 PowerShell 7 的 JSON 时间类型差异后，PowerShell 5/7 回归各 8 项通过；实际停止成功。
- `ops/run-local.ps1 -Gpu` 已成功启动独立 API、CPU worker 与 GPU worker，完成实际停止及再次启动验收，研究发现保留。

测试使用独立环境与数据库，未将原始历史数据库作为测试写入目标。数值断言、来源约束与缺失数据边界未因界面重构而放宽。

## 尚未完成

Linux systemd 与反向代理模板已提供，但 Linux 现场部署、远程 HTTPS、多用户权限隔离、移动设备实机验收尚未完成。单工作空间令牌不是多人账户体系。

独立科学验证、新的留出评价、科研消融和研究者试用仍需适用数据与实验条件。已有回放、导入验收和本机流程测试不替代这些工作。部署与交付范围见[CPU 部署](CPU部署.md)和[交付说明](交付说明.md)。
