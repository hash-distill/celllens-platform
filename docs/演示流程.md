# 演示流程

以下案例来自当前隔离副本的真实运行或经哈希验证的历史结果。打开本地服务 `http://127.0.0.1:8028`。答辩前保持服务在线，并提前打开完成结果，避免把现场长计算作为唯一展示路径。

## 约四分钟的主线

1. **研究概览，约 30 秒。** 介绍平台围绕扰动研究组织数据、表达与功能证据。切换细胞结构的三维/二维显示，并明确这是结构导航，数值证据来自真实分析。
2. **公开实测，约 60 秒。** 打开 `measured_00c6134fec4544efb1ad3b6d`。本次 K562/ALDOA 实际使用 754 个对照细胞、77 个扰动细胞和 6,546 个共同基因。切换 PCA/UMAP，再点击结构示意的内质网 → N-连接糖基化，核对两组评分、6/6 基因覆盖、关联反应及 GPR；点击 DAD1 返回表达证据。
3. **基因扰动预测，约 60 秒。** 打开新执行的 `run_feb6ebf11ef747ab`（Jurkat/ALDOA，64 个预测样本，种子 20261107）。分别查看原模型群体与匹配实测诊断：原细胞汇总误差比 0.936，批次等权为 1.143，界面会提示结论依赖批次权重。不要将单个案例的表现推广为整体泛化能力。
4. **来源与发现，约 45 秒。** 打开证据抽屉，说明输入/方法指纹；选中任务保存一条明确标注为演示的研究笔记，再下载研究记录 JSON。预测导出的原运行表和匹配表各自标明群体与来源。公开展示版本不会暴露私人笔记。
5. **自有数据与可靠执行，约 45 秒。** 展示自有 H5AD 的尺度、分组和输入版本核对。验收记录 `measured_ad6bdad81013413493d363db` 使用从真实公开数据构建的 16+16 细胞子集，经历一次人为 worker 中断后以 attempt 2 完成。它是工程验收案例，不是新增生物学实验。

## 评委追问时可直接展示

- 输入范围：数据图谱中的固定公开源、版本、细胞背景与模型支持。
- 量纲：表达差值定义、scCellFie 支持分数、同任务跨组比较。
- 可复现性：种子、输入指纹、结果指纹、包版本和数值表。
- 工程可靠性：API 与 worker 分离、真实心跳、attempt 历史、取消与不可变结果。
- 现实边界：还需要独立模型验证、研究者试用及部署目标上的性能验收；软件演示不等于这些工作已完成。
