# 使用说明

CellLens 面向单细胞扰动研究，提供实测数据分析与基因扰动预测两项任务。实测任务支持公开数据和自有 H5AD 两种来源。分析围绕一个细胞背景与一个扰动条件展开；所有数值结果都需要有可核验的输入和方法来源。

## 开始研究

在「研究工作台」选择分析任务；实测任务再选择公开数据或自有 H5AD，设置条件后核对摘要并提交。任务进入持久队列；离开页面后可从「实验记录」继续打开。

| 路径 | 输入 | 运行条件 | 输出 |
|---|---|---|---|
| 公开实测 | 固定来源中的细胞背景、目标、采样上限和种子 | CPU worker 与可用真实输入 | 表达均值差、PCA/UMAP、可用的功能任务支持分数 |
| 自有数据 | 受控目录内的 H5AD、分组列、组标签、表达尺度 | 本地/私人工作区启用导入、CPU worker | 独立输入快照、来源指纹和实测比较 |
| 基因扰动预测 | 当前模型词表支持的背景和扰动、预测数与种子 | 已核验模型/输入、实际在线的预测 worker | 模型表达响应、功能证据及可用的匹配观测诊断 |

公开源未收录某个组合，不意味着全球没有测量。模型支持词表也不意味着该组合已获得泛化验证。系统不会用随机数补齐缺失结果。

## 自有 H5AD

导入页会显示当前本地/私人工作区的实际受控目录，并提供字段样例与只读检查代码。将文件放在该目录，只填写相对路径，例如 `experiment.h5ad`。接口不浏览服务器任意目录，也不接收 `../` 或绝对路径。

- `X` 必须是明确声明的 `raw_counts`、`CP10K` 或 `log1p(CP10K)`；不根据数值自动猜尺度。
- 基因身份必须有效且唯一；分组列和两组标签必须存在，不能选择同一组作为对照和扰动。
- 原始计数如果已裁剪基因，必须提供每细胞的**全库总计数列**，不能用裁剪后面板的行和代替。
- 若声明原始矩阵包含完整文库，系统先计算全库分母，再选择共同基因。已声明 CP10K 的输入不会重新按当前面板归一化。
- 文件中的背景信息须与输入声明一致。批次列可选；批次匹配、实际细胞数和限制会写入结果。
- 当前限制为 256 MiB、20,000 个输入细胞、60,000 个基因及 12,000,000 个矩阵元素；实际安装可进一步限制文件大小。选择更小且有明确来源的样本，不代表获得独立验证。

先执行「校验并建立数据版本」，核对两组数量与尺度，再提交分析。修改输入需要新建版本。失败重试绑定原输入版本，不会切换为公开源或调用不适配的预测模型。

## 阅读结果

「研究总览」先展示群体、表达和功能摘要，再提供真实表达投影与细胞结构知识导航。结构图支持选择、旋转、缩放、复位、暂停与二维替代；**结构图不由本次 RNA 预测形态，也没有把表达坐标映射到细胞器物理位置**。

「表达响应」查看具体基因及群体表达。`mean(log1p(CP10K))` 的组间差不是 log2 fold change。零值保留为零，缺失数据单独标记。

「功能证据」按覆盖、分类和名称寻找任务，核对同一任务的不同群体。实测任务可继续查看该版本知识库关联的反应、GPR 规则、已覆盖与缺失基因；点击已覆盖基因可回到表达证据。内质网与高尔基体只连接知识库明确记录的分类，其他结构不推测定位。不同任务的原始分数尺度不同，不用跨任务的绝对分数或差值排名宣称“整体活性”。scCellFie 分数属于表达派生的功能支持，不是代谢通量、酶活测量或因果机制。

「实验对照」在实测研究中展示两组数量、采样/批次匹配和描述性比较；在模型研究中展示已有的匹配观测诊断。原汇总估计与共同批次等权敏感性分别显示。首次使用可明确点击准备诊断；该步骤仅读取已有矩阵，不重新运行 STATE。若两种权重下的基线结论不一致，页面明确提示“依赖批次权重”。功能一致性同时展示输入覆盖分层，细胞级 DE 仅作探索性诊断。未确认训练排除时，诊断不称为独立留出验证。

预测页投影明确使用原运行群体，匹配诊断群体在总览摘要与实验对照中分别标识。投影优先读取冻结的真实 PCA/UMAP。无法核验、标为随机投影或缺少产物时，页面说明原因，不现场编造坐标。筛选群体保持完整数据的共同轴域，显示当前可见数量与冻结参数；表达空间位置与细胞运动无关。

## 保存和导出

在图表或任务表中选中关注对象，点击「保存发现」。笔记会绑定结果编号、选择条件和来源指纹，独立存入数据库，不改写原结果文件。

「来源与证据」可查看输入、单位、方法、可用模块和限制。「研究记录 · JSON」提供 JSON 研究包，包含数值表、结果契约、脱敏来源清单及私人工作区的研究笔记。阅读报告（实测 HTML、预测 PDF）、完整包（ZIP）与完整表（CSV）保留在「导出与更多」和详情中。匹配比较的 CSV 附带完整比较指纹、观测输入指纹与选择说明，可配套下载完整来源 JSON。统一预测 JSON 的原表标记 original，匹配表单独放在 population_exports.matched_comparison，并有独立群体与指纹。公开展示的研究包不包含私人笔记。

## 运行异常

- 提交超时：先检查实验记录。页面不会自动重发，避免重复计算。
- worker 暂时不可用：已排队记录保留；状态页反映实际进程心跳。预测不可用时不能发起新的模型任务。
- 取消：先记录取消请求，worker 停止计算后确认。预测取消沿用历史 `failed` 枚举，同时标记 `RUN_CANCELLED`，不作为完成结果发布。
- 中断恢复：worker 在租约过期后建立新 attempt，使用独立暂存目录恢复；已完成结果不被覆盖。
- 文件或知识库校验失败：停止展示受影响结果。保留原文件并核对资产版本，不能通过改写哈希绕过检查。

本版私人部署采用单工作区访问口令，不提供多人账户隔离。公开展示只允许已选定的完成案例；完整分析在本地或私人工作区使用。
