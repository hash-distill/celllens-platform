日期：2026-10-04  
状态：用户已选择“浅色工作台＋深色三维视窗”；本文件与三张效果图是待审阅设计，不是已部署界面。

## 1. 设计判断

当前前端存在主区域被入门说明占据、卡片层级雷同、三维视觉入口缺失、实现说明混入操作界面的问题。新页面让用户先看到研究对象，再配置实验和核对结果。视觉记忆点是“浅色专业仪器界面中的深色细胞剖面”；可信度来自来源标记、正确的数据编码和随时可打开的明细。

比较过三个方向：

| 方向 | 收益 | 代价 | 选择 |
|---|---|---|---|
| 浅色工作台＋深色三维视窗 | 文字和表格清楚，细胞是视觉中心，兼顾研究和投影答辩 | 深浅区域需统一边界和配色 | 用户已选 |
| 全深色科研仪器 | 沉浸感强，三维与图表易融合 | 密集表格和长时间使用的可读性需要额外调校 | 备用 |
| 以生物插画为主的展厅 | 第一眼吸引力强 | 操作效率和科研工具感较弱 | 不采用 |

## 3. 全站结构

| 页面 | 路由建议 | 主任务 |
|---|---|---|
| 实验工作台 | /workbench | 配置实验、浏览结构、读取最近实验 |
| 实验结果 | /runs/:runId，保留既有 tab 查询参数 | 查看表达、基因、代谢和验证记录 |
| 实验比较 | /compare | 并列比较同协议实验，检查适用条件 |
| 答辩演示 | /demo，可指定一个真实运行或明确的示例场景 | 手动推进一次完整讲解 |
| 方法与来源 | /about，并由对象检查器打开当前来源详情 | 查询方法、资产、缺失与验证状态 |

实验工作台与实验结果共享“工具栏＋左停靠区＋中央视窗＋右检查器＋底部结果区”的壳层，不另做宣传首页。当前路由、创建、轮询、下载和候选记录继续承接现有 store/API 逻辑。

### 桌面尺寸

1920×1080：顶部工具栏 52px，实验上下文条 44px，工具轨 52px，左面板 240px，右检查器 280px，底部状态条 24px；中央占剩余空间。工作台三维视窗约占可用中央高度 70%，结果坞约 30%。不要给所有区域加外层圆角卡片。

1440×900：左面板 220px、右检查器 250px，中央优先；图表与表格按任务切换。1366×768：默认折叠右检查器，通过显式按钮打开，保留约 800px 的中央工作区。窄于 1100px 时面板改为抽屉；窄于 768px 时结果列表可用，三维交互提示使用桌面视图。投影答辩优先使用 16:9 演示模式。

## 4. 实验工作台

效果图：01-workbench.png。

首次进入即可看到标注为“结构示意”的三维细胞和实验设置。没有真实运行时，底部保持“尚未运行”或明确的示例状态，不出现真实来源徽标。

左侧包含细胞背景、单个扰动、模式、样本量；seed 收入高级参数。只展示 catalog 支持项，不提供当前不可用的 RPE1 或多基因联合扰动。下方为场景树和最近实验；场景树只控制可见性与选中对象，不改写科学数据。

中央三维示意包括细胞膜、细胞核/核仁、线粒体、内质网、简化高尔基体。默认三分之四视角和可调剖面，不旋转整个页面。拖动旋转、滚轮缩放、点击选择、复位、全屏、图层显隐必须可用。剖面滑块改变几何裁剪位置，不表示生物时间。图稿中的测量/标注图标不属于首版必做能力：没有真实几何校准，不显示微米标尺、体积或测量工具。

右检查器展示当前对象名称、示意说明、已有结果与来源。点选线粒体不自动声称“线粒体功能增强”。没有经审核的任务—区室映射时，显示“尚无关联结果”，保留结果页入口。

底部结果坞显示实际运行状态或结果摘要，初始可折叠。成功后突出少量数据并链接完整结果；运行过程显示后端真实阶段，不播放伪进度。详细模型/资产哈希位于来源面板，底部状态条只显示服务和当前操作。

### 三维材质与性能

使用真实可拾取的三维几何、材质和灯光。效果图是材质及构图目标，不能将整张图片贴到 canvas 上宣称实现三维。首版以可读轮廓、内部层次和连贯操作为优先，细胞膜半透明，细胞核低饱和灰紫，线粒体赭金；有限高光，不使用发光粒子或持续脉冲。

优先程序化几何或来源清晰的可用模型，资产随项目保存，离线可用。膜使用降低复杂度的网格；线粒体实例复用；默认限制像素比不高于 1.5；低配置关闭复杂透明层和抗锯齿效果。静止时减少无意义重绘，隐藏页签暂停。图层树、选择与参数区仍能在 WebGL 不可用时工作，并明确显示静态示意回退。

“细胞结构”和“表达空间”是两个不同视图。结构描述解剖示意，表达空间描述高维数据关系。不能把表达坐标塞进细胞器位置，也不能根据表达变化改变线粒体数量或细胞大小。

## 5. 结果分析页

效果图：02-analysis.png。

左侧为分析视图、来源图层、搜索与选择列表；中央是图形＋明细；右侧为当前基因/任务和来源。图形与表格相邻，点击一条基因记录同步突出差异条形和检查器。

表达空间首版读取当前二维随机投影。对照与预测叠加，观测只在后端提供时显示。保持方法名与来源，不将随机投影写成 PCA/UMAP。无投影文件时显示局部不可用，其他结果可浏览。

基因响应使用每个基因一个从零线出发的有符号差异条；不把同一差异同时画到两边。基因结果表读取完整可用接口行，搜索、排序、分页、CSV 导出沿用现有能力。图稿中的示例值只展示排版，不代表 MYC 的真实方向或效应。不存在 p 值就不显示火山图或显著性星号。

检查器中的基因分布是待后端支持的示例构图：当前只有均值和差异，不能绘制成真实单细胞小提琴图。首版替换为对照/预测/差异的紧凑数值和柱形；接口提供分布摘要后再启用。基因—任务列表在 mapping 缺失时显示明确空态，不能自行编造关系。

代谢任务页使用排序的有符号差异图＋覆盖列＋可筛选明细表。覆盖支持/探索性/覆盖不足采用克制的文本和细标记，不写成“已验证/可信概率”。任务评分称为任务评分，不写成实测通量。

验证页用实际指标、样本数、匹配观测与协议状态组成可追溯的表格；没有观测时显示未提供。protocol_status=unconfirmed 时保持醒目的“协议待确认”，不以绿色完成徽标替代。来源抽屉展示本次 manifest，不用当前 catalog 覆盖历史版本。

### 三维表达空间扩展

这是单独的后端能力扩展，不能靠给二维点随机补 z 实现。需要从同一批表达矩阵、统一的变换与基底生成真实三个投影维度，记录算法、种子、版本和抽样；对照/预测/观测共用空间。旧运行没有三维产物时保留二维。该功能不阻塞三维细胞结构示意和首版结果页。

## 6. 实验比较页

选择 2–4 个已有运行，顶部是紧凑的运行列头；主体为同一基因/任务在各实验中的矩阵、统一横轴的差异图及明细。每列常驻背景、扰动、来源、版本、样本量和验证状态，不放每个实验一个巨大卡片。

默认只比较同背景、可比模型/面板/任务库的运行。版本或方法不同则标注差异，不给自动冠军、治疗效果或优先级评分。原始运行之间投影坐标不保证可比，不能叠加；没有共同嵌入就不提供叠加按钮。缺失任务显示“—”，不补零。导出保留源运行与协议说明。

## 7. 答辩演示页

效果图：03-presentation.png。

进入后收起常规参数区与复杂数据表。中央三维或分析图占 70% 左右，右侧是当前章节解释和少量实际结果，底部是章节控制。共四章：实验设定、细胞结构、结果解释、证据核对。

四章复用同一个场景和当前运行数据。上一章/下一章、暂停/继续、键盘方向键和退出可用；自动推进只播放章节与镜头，不重新触发推理。切换章节不改变历史实验参数。进入新章可平滑调整镜头、选择区室或切换结果图，任何时候都能停下来查看完整表格或来源。

说明文字采用“选择了什么、结果是什么、如何核对”的顺序。没有数据时演示结构和流程，结果图明确标为示例。真实运行可选择一个已完成运行进行展示，顶部常驻“真实运行结果”；若没有适用的任务—区室映射，讲解停留在结果列表，不强连到线粒体。

真实预测和对照的切换只切换数值、图层与注释，三维结构不变形。“对照→预测”不是时间序列动画。点击演示按钮不会默默转入 Mock。预计算和前端示例分别说明来源。

## 8. 数据与空态规则

| 内容 | 当前能力 | 首版行为 |
|---|---|---|
| 单扰动创建、阶段轮询、结果报告 | 已有 API 与 store | 重用并改界面 |
| 二维投影、基因差异、任务/反应 | 已有结果接口，部分运行可能缺失 | 读取真实产物，局部空态 |
| 细胞三维解剖结构 | 当前没有三维组件 | 新增独立示意模型，明确来源 |
| 三维表达投影 | 当前只有 x/y | 后端产物扩展后再启用 |
| 单细胞基因分布 | 当前公共接口只有均值/差异 | 暂不画小提琴图 |
| 基因—反应—任务与区室映射 | 当前 determinant_genes 为空、无审核映射 | 空态，不画因果流图 |
| 覆盖与实验验证 | 覆盖可用；正式验证协议待确认 | 两类信息分开显示 |
| 多候选比较 | 现有最多 4 个浏览器记录 | 先标可比条件，再展示差异 |

未开始、排队、运行、失败、完成、结果缺失、服务断开分别使用简洁真实状态。警告按影响区域显示；不可用的按钮有具体原因。创建任务不会因超时自动重发，失败不会自动开启演示数据。

## 9. 演示资产与验证

演示资产应包含示意模型、镜头预设、经标注的示例场景和来源说明，均保存本地。真实结果选择已有完成运行，不能硬编码某台机器的 run_id。新入口与旧路由保持可达，后台/API 接口契约变更单独核查。

验收关注：
1. 初次进入没有说明书式大卡片，实验设置、研究对象和下一步操作一眼可见。
2. 三维支持旋转、缩放、选择、图层显隐、剖面与复位；失去 WebGL 时有明确回退。
3. 选择对象后检查器同步；无映射时正确空态；缺失数据不由示例代填。
4. 真实运行可创建、轮询、读结果、加入比较、下载；演示状态不会冒充真实运行。
5. 1440×900 与 1366×768 无遮挡，1920×1080 演示文字可在投影中读清，窄屏面板可收起。
6. 键盘可操作关键控件，焦点可见，图表使用文字/形状辅助编码，减少动态效果有效。
7. 桌面浏览器稳定播放三维场景；测量实际帧率和负载后调节几何/透明度，不预先声称达到某帧率。
8. 演示可手动完成四章并回到详细结果；中断、刷新和退出不丢失当前运行上下文。

## 10. 交付说明与实现顺序

当前交付是设计包；frontend/src 与 backend 源码尚未改造，尚无可交互演示。三张 PNG 由内置 image_gen 生成并人工检查，提示词保存在 IMAGE_PROMPTS.md。图中少数新增控件和样例图按本规范确定取舍，不将生成图当成 API 能力证明。

建议实施顺序：全站壳层与样式 → 可交互三维结构与检查器 → 结果图/表联动 → 四章演示 → 比较与来源 → 尺寸/交互/真实运行验收。三维表达投影和分布/关系接口后续独立扩展。

设计审阅时确认页面构图与演示叙事；进入代码实现后，应提交实际页面截图与交互验证证据，区分已落地部分和仅作为视觉目标的精细材质。
